# Support

This is a Windows preview, not a hosted service. Maintainers prioritize the newest preview and do not promise fixed response times or indefinite support for older versions.

Read [first setup](docs/FIRST_RUN_WINDOWS.md), [Owner guide](docs/OWNER_QUICK_GUIDE.md), [compatibility](docs/COMPATIBILITY.md) and [upgrade/rollback](docs/UPGRADE_ROLLBACK.md). When a repository is published, use its bug or usage-question issue template. No GitHub repository or support endpoint has been created by this local package.

Report only version, Windows/Node/CLI version, selected brain type and a minimal reproduction using synthetic data. A model being at capacity, unavailable, or unable to complete a task is different from a controller crash. Explain what actually failed; do not upload your entire runtime.

Private security issues follow [SECURITY.md](SECURITY.md). Never include full control links, account credentials, individual identities, memories, conversations or unredacted logs. Maintainers cannot access or restore your local data; keep cold backups. Do not repeatedly create or authorize an individual to work around a disconnected page.
