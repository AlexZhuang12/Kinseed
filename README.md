## Hedra and document tools

Opt-in image/video/music generation with scoped credits, reservation and recovery; generated document readback and saved PDF page viewing. Bring your own accounts; no credentials or individuals are shipped. See [Hedra operation](docs/HEDRA_FOUNDATION.md), [current feature limits](docs/RELEASE_1_13_0_PREVIEW.md) and [proposed next stages](docs/HEDRA_WORKFLOW_ITERATION_PLAN.md).

## Current tools and console

Guided pink interface, scoped tool permissions, Hedra model inspection and saved media, local film composition, PDF layout and queued page previews, and opt-in local Whisper dialogue transcription. See [current version and acceptance scope](docs/RELEASE_1_13_0_PREVIEW.md), [console journey](docs/OWNER_CONSOLE_JOURNEY.md) and [Whisper setup](docs/WHISPER_SERVICE.md). No model weights, account credentials or existing individuals are included. Permissions remain off for a new installation; generating paid media and sending email require the configured approval flow. Speech transcription is not emotional, musical or artistic listening evaluation.

## Consultation and report reliability

Consultations return a durable job ID for later readback without cancelling future daily consent on a settled failure. Report sources now handle exact multiline quotations, preserve self-report attribution, and permit one model revision after an unsupported-content review, retaining independent checks. The general installation now includes manual and scheduled reports, using its own configured brain, time zone and private data. See [release scope](docs/RELEASE_1_13_0_PREVIEW.md), [second-computer installation](docs/SECOND_COMPUTER.zh-Hant.md) and [AI acceptance](docs/acceptance/PUBLIC_1_13_0.md).
