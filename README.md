# Kinseed

Windows preview **1.12.0-preview.1**. An Owner-controlled environment for individual identity, memory, daily activity and scoped tools, using Codex or a local-model adapter.

Use the [English guide](docs/USER_GUIDE.en.md), [繁體中文](docs/USER_GUIDE.zh-Hant.md), [简体中文](docs/USER_GUIDE.zh-Hans.md) or [日本語](docs/USER_GUIDE.ja.md). On Windows with Node 24.19.x, run the included first-setup CMD after cloning. It installs locked dependencies with install scripts disabled, helps select a brain and prepare tools, and starts your own empty private runtime. Models and logins are yours. No private individual data is included.

See [release notes](docs/RELEASE_1_12_0_PREVIEW.md), [daily consent and recovery](docs/LIFE_AUTHORITY_AND_RECOVERY.md), [acceptance policy](docs/AI_ACCEPTANCE_POLICY.md), [compatibility](docs/COMPATIBILITY.md) and [security reporting](SECURITY.md). This is a preview. Model adapters do not imply full-life qualification of every model.

Apache-2.0 applies to original code; third-party notices remain applicable.

## Hedra and document tools

Opt-in image/video/music generation with scoped credits, reservation and recovery; generated document readback and saved PDF page viewing. Bring your own accounts; no credentials or individuals are shipped. See [Hedra operation](docs/HEDRA_FOUNDATION.md), [current feature limits](docs/RELEASE_1_12_0_PREVIEW.md) and [proposed next stages](docs/HEDRA_WORKFLOW_ITERATION_PLAN.md).

## Current tools and console

Guided pink interface, scoped tool permissions, Hedra model inspection and saved media, local film composition, PDF layout and queued page previews, and opt-in local Whisper dialogue transcription. See [current version and acceptance scope](docs/RELEASE_1_12_0_PREVIEW.md), [console journey](docs/OWNER_CONSOLE_JOURNEY.md) and [Whisper setup](docs/WHISPER_SERVICE.md). No model weights, account credentials or existing individuals are included. Permissions remain off for a new installation; generating paid media and sending email require the configured approval flow. Speech transcription is not emotional, musical or artistic listening evaluation.
