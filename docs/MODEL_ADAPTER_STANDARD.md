# 模型接入基本標準 v1：產品責任與模型相容性分開

範圍：獨立 Windows 候選。原 native／schema／staged／guided 相容保留；新增可選 stepwise。無正式部署或自動啟用。

## 產品必須符合

| 編號 | 必須保證 | 驗收方式 |
|---|---|---|
| S01 | 不修改身份、任務、主觀記憶，不加探索或等待偏好 | 輸入原文及模型輸出逐段核對；空記憶亦不代補 |
| S02 | 提供完整目前身份／記憶，或明示身份續讀入口與完整性旗標 | 原 context 對投影核對；只有當輪路由及歷史出生副本省略並留證；身份未齊且無續讀工具時拒絕 |
| S03 | 呈現可逆、不同 ID／版本角色清楚 | 逐行資料可還原投影；系統ID／身份原文、記憶版本／身份版本分區 |
| S04 | 每次只提出一個動作，取得真實結果後再決定 | 真實 MCP 往返，後一步輸入有前一步輸出與收據 |
| S05 | 模型自己選工具、填內容、寫記憶、選等待 | 模型原文直達原 MCP；系統僅綁 request_id／提交 expected_version |
| S06 | 原工具 Schema 為最後權威，不接受模型覆寫路由 | 跨工具格式、未知工具、路由覆寫皆拒絕 |
| S07 | 不重做已成功的相同參數寫入、不重送相同失敗操作 | 原執行前防護；最多兩個未執行問題提示，由模型改選，不假造第二張收據 |
| S08 | 格式修復有限；未知、外部及寫入不自動重試 | 未執行驗證通知與真正 MCP 收據分開；最多兩個通知，模型全輪仍17次 |
| S09 | 記憶更新原子且不代寫；提交被拒或取消時保留舊A與已完成產物 | 真實 SQLite／MCP；新一輪讀回完全等於上一輪模型提交；模型合法清空／改寫不被工程擅自補回 |
| S10 | 執行事實由真實收據記錄，不要求模型抄寫行政證據 | 系統獨立保存收據雜湊；不宣稱模型敘事經語意查證 |
| S11 | 原權限、個體隔離、16工具、120秒、停止、未知收尾有效 | 拒絕、停止／時鐘／斷線與 worker／lease 測試；不殺共用服務 |
| S12 | 可觀察且可回退，不暗中換模、增權、恢復或升級正式 | 來源／模型固定、狀態分類、正式保留核對；移除候選選項即可停用 |

S10 與 guided 的差異：不再要求模型在記憶草稿另外重抄 execution_claims。執行證據始終來自原受控 MCP，完整紀錄與原權限檢查沒有減少。新結果 receipts_verified=true 表示真實工具收據已記錄；claims_verified=false、narrative_verified=false，不暗示模型文字正確。模型聲稱成功不能建立收據，也不能被標成任務全部成功。

## 模型相容性另行驗收

固定同一合成材料，檢查身份／版本提取、參數、合法拒絕後自主下一步、筆記、新事實記憶、跨輪承接及期限內完整提交。模型相容性失敗，不可靠工程代答或放寬安全取得通過。產品標準通過也不等於任意模型均可用；應將實際結果及未測情境公開記錄。

本次使用既有 Qwen3 1.7B Q4_K_M／原執行設定做有限真實驗證，不下載、訓練或換正式模型。單一固定身份與少量案例不是所有模型的能力證明。

## 使用候選與回退

先停止自己的開發控制台，將 `config/local-model.example.json` 另存為私人的 `config/development.local.json`，選擇自己已安裝且允許使用的模型及獨立服務位址。`inference.tool_protocol:"stepwise"` 明確選用此流程；省略此欄位的舊設定仍維持 native，不暗中切換。範例大腦仍停用，預算僅為範例，不代表任意電腦已通過該上下文／輸出大小的實測。啟用與生活授權是分開的動作。

不能在工作中切換，不能用本候選連接其他環境的資料庫或批准正式個體。未知本地模型工作不因HTTP取消就假裝已停止；不得停止其他人共用的模型服務來清除自己的工作位置。實際模型驗證必須使用自己的獨立服務，並確認退出。

回退先確認本候選工作已收尾，再改回原 tool_protocol 或移除此可選欄位；保留私人DB及歷史，不以舊資料覆蓋。沒有正式部署，自然也不需改動正式控制器或恢復任何生活。

## 本次驗收範圍

195項候選回歸通過，含真實MCP／SQLite但模型HTTP為明示合成的產品機制驗證。另用同一既有Qwen3做真實對照與最終來源試驗；有正常提交，也有漏寫指定內容、改寫舊記憶及完整工具目錄逾時，模型完整生活資格未通過。模型原始文字沒有被工程補齊。

機制通過不代表任務內容全對。任務成功、模型敘事、原子提交、工具結果與取消收尾必須分開看。完整結果與版本差異見根專案 `evidence/adapter-standard-20261022/DELIVERY_REPORT.md`。
