# 資料與對外連線

本版是單一 Windows 使用者的本機預覽，沒有多人帳號或雲端代管安全邊界。

## 留在本機的資料

身份、記憶、對話、原始歷史、作品與日誌存於本副本 `.private/`，個人設定在 `config/development.local.json`。這些資料和維護備份未加密；同一 Windows 使用者及管理員可讀取。請使用 Windows 帳號保護、磁碟加密與自己的備份政策。

Owner 控制連線含短效能力。不要分享完整控制網址、session.json 或瀏覽器儲存內容。跨瀏覽器連結也相當於這次控制台的鑰匙。控制台與設定頁只綁定 127.0.0.1；不能直接當作公開網站部署。

## 何時會對外連線

| 動作 | 傳出內容與對象 |
|---|---|
| 安裝依賴、Codex 程式 | 固定公開 npm registry 取得套件；遠端可看到 IP、套件及版本。安裝不帶個體資料。 |
| Codex 作大腦、請教或報告 | 任務所需身份、記憶、對話或報告材料交給使用者登入的模型服務；使用前應理解服務條款。 |
| 本機 Ollama 作大腦 | 請求送至設定的本機 loopback 服務；Kinseed 不自動 pull。Ollama 程式本身的外連行為依其設定。 |
| 委派 Codex 工具 | 即使大腦使用本地模型，選入作品、指令與本次結果仍會送給 Codex。這不是完全離線模式。 |
| 個體已獲准瀏覽網路 | URL、搜尋內容及經允許的資料送往外部網站，依工具權限、資料邊界與預算執行。 |
| `npm audit` | 將套件名稱與版本送給 npm 的漏洞服務；不提交個體資料。它是維護者主動檢查，不是常駐上報。 |

本次靜態盤點未發現專案自行接入遙測 SDK；這不保證第三方程式、登入服務或瀏覽器完全不外連。Codex 登入沿用同 Windows 使用者正常的 Codex 登入位置，並不是 Kinseed 的獨立帳號保險箱。

## 公開來源與問題回報

只發布允許清單匯出的來源，不對原私人專案執行 `git add .`。`.gitignore` 不能移除已被 Git 記錄的私人資料。每次發布需檢查乾淨來源與 ZIP，不直接分享 `.private`、原工程 evidence、螢幕截圖或失敗日誌。秘密掃描只找已知形狀，另由AI核對散布清單及內容；不宣稱獨立人類審查或無未知秘密。

回報問題時只提供版本、步驟及去識別化錯誤，不貼身份、記憶、能力網址、憑證或私人原文。正式 GitHub 尚未建立；發布時需另外設定私人安全通報管道，未設定前不要把安全漏洞與私人資料貼入公開 issue。
