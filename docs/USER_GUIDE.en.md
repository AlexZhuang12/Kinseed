# Windows user guide

[繁體中文](USER_GUIDE.zh-Hant.md) · [简体中文](USER_GUIDE.zh-Hans.md) · [日本語](USER_GUIDE.ja.md)

This is a local Windows preview. You keep your own data. Install Node.js 24.19.x and provide disk space and internet access. Isolated web browsing requires Chrome. This source package contains no model, Codex binary, account, or existing individual.

## First setup

1. Extract the source or clone it into your own folder. Never overwrite an existing `.private` directory with a source package.
2. Run `首次設定.cmd` and keep its command window open. Choose Traditional Chinese, Simplified Chinese, English, or Japanese at the top. Language does not change stored content or the life timezone.
3. Step 1 checks and installs locked dependencies for this copy. It does not download models.
4. Step 2 selects the life timezone and brain. Choose no brain to explore identity drafts first. Codex requires your own login and the supported CLI. For Ollama, prepare a model yourself and select its local service. A service check is not a life-capability test.
5. Step 3 optionally prepares the controlled Codex work tool, even with a local brain. Explicitly delegated tasks and selected works are sent to Codex and may use your account budget. Preparing the connection grants no individual permissions.
6. Review and save in step 4; start and enter the console in step 5. This never births or resumes an individual automatically.

New installations use the selected life timezone for daily hours and budgets. Existing data keeps its original timezone. Legacy data without a timezone remains Asia/Taipei. Changing a configuration file must not reinterpret existing life schedules.

## Create an individual

1. From Home, create an individual and give it a name. Internal identifiers only separate data.
2. Start its birth conditions. Complete eight domains and 24 questions using the fictional examples if useful. Examples are not standard answers and never fill themselves in. Only self-description is required; other questions can be explicitly skipped.
3. Save each page and proceed. To return later, select the same individual and Continue. A separate blank draft is an alternative proposal, not the normal continuation path.
4. Preview conditions, sources, and omissions, then submit for review. Verify the recipient, version, and differences before personally approving. Reading an original creates no version; saving an edited copy does. Approval does not cause birth.
5. Follow Next through hours, model rounds, and tool permissions. Save each, then return to birth preparation. Saving never starts life or resets usage.
6. If the brain is not connected, save first, return to First setup, stop this console, configure the brain, and restart. Identity and drafts remain.
7. Check the platform. For global stop, review the affected scope before deciding to clear it. Clearing does not birth or resume others.
8. Verify the name, identity, full first-activity date, deadline, and round limit. Personally check and confirm first birth. Birth can happen now while activity waits until the scheduled time.

Birth is permanent; stopping activity does not undo it. Expiry, stopping, and restart do not trigger automatic catch-up. One-time sessions are under Manage individuals → Status and controls; daily hours are under Hours and budgets. Individual and platform model limits both apply. Network budgets are separate and do not fully measure model traffic or TLS overhead.

## Read and manage

- Individual messages supports reading, replies, and marking read. Reading never resumes life. Messages stay saved without background notifications.
- Tool work and outputs → Works and execution shows original text, immutable versions, and actual isolated results. It does not run arbitrary HTML in the console.
- Memories and records shows versions and textual differences. The journal groups B history by life-timezone date. Reading uses no model rounds.
- Switching individuals only changes the view. Identity, memories, works, permissions, and history remain isolated.
- The daily LLM report service is disabled in this open-source preview. A disabled button is not an enabled feature.

Closing the browser does not stop the service. Use this copy's Stop launcher. Reopen with `開啟開發控制台.cmd`. Across browsers, use Copy console link in First setup, not just the address bar. The complete link grants control: never share it or include it in issues.

Temporary model failures retry only under safe, finite conditions. Unknown results or existing writes are not blindly repeated. If disconnected, verify the service and valid link; do not recreate the individual, repeat birth, or delete leases. Original diagnostic details may retain internal codes. Follow the plain-language recovery guidance and redact identities, conversations, credentials, and links before reporting.

Language changes preserve supported unsaved input locally without saving it to the server. Final birth confirmation must be checked again. Save progress first when possible. Stored identity, evidence, and individual content remain in their original language.

## Upgrade and support

Stop your copy and confirm no unfinished work, then make and verify a snapshot. Follow [upgrade and rollback](UPGRADE_ROLLBACK.md); retain the newest `.private` data. Never overwrite newer history with an old database. Unknown versions and existing-timezone changes are rejected, not solved by deleting data.

Support prioritizes the latest preview, without guaranteed response times. After publication, use [SUPPORT](../SUPPORT.md) for general questions and [SECURITY](../SECURITY.md) for private security reports. Unactivated GitHub channels cannot yet receive reports. Translations are engineering drafts; independent native-language review and another physical Windows test remain pending.

## Hedra image, video and music tools

Open Tools and materials, choose an individual, then Hedra media tools. First run the read-only connection check; it does not generate or spend credits. Enable this installation’s shared connection only after reviewing the billing notice, then save. Set an optional Owner reserve, explicitly select media permissions and set cumulative and single-item limits. No subscription date or original credit grant is needed. Limits do not reset monthly. Music permission does not include speech, sound effects or voice cloning. Failed paid work never authorizes a blind new generation. See HEDRA_FOUNDATION.md.
