# Kinseed 操作導引（1.2.1-preview.1）

此版是獨立 Windows 預覽版。首次設定與控制台是兩個不同的畫面。

## 第一次使用

1. 執行「首次設定.cmd」，依頁面準備套件、選大腦、準備選用工具、保存，再啟動控制台。**Codex 大腦與 Codex 作品工具是兩件事**，不需要為了思考而開放作品工具。
2. 進控制台，按「建立新個體」，填自己選的名字。這個動作不會出生。
3. 依八領域問卷填出生條件；隨時儲存。草稿是未完成的條件，日後可接續。已有條件可唯讀查看版本，或另建編輯副本；查看不會新增版本。
4. 預覽條件，提交審核，核對個體、身份版本與差異，再親自批准。批准仍不會出生。
5. 到「管理個體 → 身份與出生」，從第2步依序調整時間與輪數、工具權限。每頁下方都有下一步；各欄位先保存再繼續。有未保存內容時會提醒，不會拿未保存的輸入去出生。
6. 返回出生準備，檢查平台。如果全域停止，先查看影響範圍，由自己決定是否解除。解除不會恢復其他個體或讓任何個體出生。
7. 最後核對完整日期、開始時間、截止、輪數與身份。確認無誤後親自勾選並按首次出生。可以提前出生，系統會等到活動時間；**出生成功不等於模型已成功完成活動**。

## 接續未完成的操作

控制台左側始終有「操作導引」。管理個體上方顯示目前狀態與下一步；它依已保存資料判斷，不會替你批准、出生、開權限或恢復。重新整理保留已保存的草稿、審核與設定。未保存的表單依目前瀏覽器分頁保留，不保證換瀏覽器或關閉分頁後仍在；離開前請保存。

大腦未就緒：保存進度，回首次設定；找不到分頁時，從同一份資料夾再次執行首次設定入口。先停止這份副本，再重新選擇大腦、檢查與保存，重新開啟後選原個體繼續，無需重填身份。停止影響此副本中正在活動的個體，請先核對；不要因此重啟其他服務。

## 日常操作

| 想做什麼 | 控制台入口 |
| --- | --- |
| 查看目前是否活動、暫停、停止、恢復、臨時加開 | 管理個體 → 狀態與啟停 |
| 每天的時間、分鐘、輪數與網路分配 | 管理個體 → 時間與額度 |
| 設定可用工具 | 管理個體 → 工具權限；先停止並等待工作收尾才能保存 |
| 身份、出生與來源 | 管理個體 → 身份與出生 |
| 記憶與歷史 | 管理個體 → 記憶與紀錄 |
| 讀信與回覆 | 個體來訊；或管理個體 → 與個體對話 |
| 作品程式、版本及實際執行成果 | 工具工作與成品 → 作品與執行 |
| 日誌與報告 | 閱讀紀錄；獨立預覽版每日報告服務尚未啟用 |
| 全體停止、共用模型額度與網路 | 平台設定與共用額度 |

## 看見錯誤時

- 未保存：先保存該項，或明確捨棄；不要重新建立個體。
- 版本已變更：讀取最新設定核對，既有輸入不會被當作已批准資料。
- 無法連線：確認本副本程式仍在執行；用「開啟開發控制台.cmd」取得有效連結。跨瀏覽器請使用首次設定的複製完整連結按鈕。完整連結包含操作驗證，請勿分享。
- Codex 登入檢查失敗：先看具體原因。找不到使用者資料夾、讀取權限不足或檢查逾時不等於沒有登入；從一般 Windows 使用者環境開啟首次設定，勿停用防護或反覆登出登入。
- 等待首次活動：已出生但尚未到時間，不必重新出生或按恢復。到期、停止或控制器重啟則需另外明確授權，不會自動補跑。

## 開源文件與介面應一起提供

GitHub 的 README 負責安裝前說明、Windows 前提與首次啟動；工具內的操作導引負責當下的下一步。兩者不能互相取代。每次更新功能要一起更新本指南、介面文字與合成旅程驗收。尚需另一台實體 Windows 及未經口頭指導的新使用者試用，才能評估真正的易用程度。
