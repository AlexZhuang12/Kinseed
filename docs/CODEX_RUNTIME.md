# Codex CLI 的版本與更新

Kinseed 1.15 接受精確版本 0.164.0-alpha.11.1 與先前已驗證的 0.163.0-alpha.10.2；不自動接受未驗版本，也不更換大腦模型。首次安裝的指定版本與執行接頭共用同一份版本清單。

## 檢查與保留執行程式

在這份來源目錄執行 `node scripts/codex-runtime.mjs status`，查看實際版本與來源。若使用桌面程式附帶的 CLI，可在控制器工作收尾並關閉後執行 `node scripts/codex-runtime.mjs pin`。這會把已支援版本及三個必要伴隨程式複製至本副本的 .private/codex-runtime，逐檔 SHA256 核對後才啟用；不複製帳號憑證，不修改 Desktop 或全域安裝。也能明確傳入 `--source=<codex.exe 的完整位置>`。

固定副本優先於外部安裝。已存在的有效副本會保留；不會因 Desktop 更新自行替換。固定副本缺檔、被修改、包含額外檔案或連結時會拒絕使用，不會偷偷退回另一個執行程式。校驗證明複製與保存一致，不等於重新提供軟體供應商簽章認證。首次設定安裝的 .private/codex-cli 也是本安裝獨立位置。

## 更新與故障時

先關閉自己的控制器、備份資料、驗證新版本，再更新來源；不要只放寬版本字串。版本、登入預檢與真實工具往返是分開的檢查。既有每日授權在控制器重開後重新核對，Owner 明確停止不會被更新解除，也不補跑已錯過的時段。

固定副本避免桌面更新刪掉原始 CLI 路徑；不保證作業系統或宿主程式終止的控制器仍能存活。長時間運作請從 Windows 自己雙擊正式啟動入口並保持電腦運行。此版沒有新增自動重啟守護程式，也不會關閉 Desktop 自動更新。
