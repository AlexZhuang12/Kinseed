# 候選功能統整

正式基線1.7.1-local.1；整合候選目標1.11.0-local.1，仍只在獨立staging驗收。這張表不等於正式部署或權限授權。

| 功能 | 正式基線 | 本輪統整內容 |
|---|---|---|
| 身份、出生、記憶、每日生活、安全暫停、原額度 | 已有 | 保留原核心，逐檔核對，不重新設計原生條件 |
| 材料、程式、文件、OCR、公開資料與受控Gmail | 已有各自能力／限制 | 保留原功能與授權界線，不搬入工程帳號 |
| PDF標題與多頁預覽 | 可製作／讀取／預覽 | 納入標題與正文跨頁改善、有限排隊與原文保留 |
| Hedra | 已有模型查詢、點數、成果保存／觀看等 | 納入候選圖片參考、語音與音效接口；與音樂及原權限分開，沒有生成扣點測試 |
| 本地影音 | 未正式開放新能力 | 納入工程版本、裁切組片、配音軌、字幕、輸出、畫面／規格／波形及技術核對；量測不等於聽懂 |
| 聲音對白 | 未正式開放hearing | 納入已驗證Whisper接口、逐份同意、全零PCM前檢與保留原文的可疑提示 |
| 語氣／音樂理解 | 未驗 | 保留可替換接口，尚無通過驗證的實際語意模型，不宣稱已支援 |
| Whisper管理 | 無 | 新增Owner專用啟停、固定端點、狀態／記憶體說明、工作收尾及明確復原 |

初次比對候選來源：429檔與正式相同、45檔不同、55檔新增；之後加入本輪管理程式／文件。正式獨有的操作指南不列入刪除。實作與衍生檔各有用途，不把產生的四語檔誤當四套不同核心。

既有生活、權限及記憶資料不複製到候選。原正式依賴的版本與完整性需逐項一致；新本地影音依賴另列，不安裝額外使用者套件或新模型。新能力預設關閉，Owner之後另行開放；程式更新不自動授權。
