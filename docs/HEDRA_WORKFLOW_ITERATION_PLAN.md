## 全程共用驗收

- 每階段先合成故障，再進真實只讀；付費驗收另取得具體預算。
- 訂閱日期與原配發量不作前提，依MCP實際回應與Owner累計／單件上限運作。
- 連線失效、拒絕、額度不足、價格改變、排隊、斷線、回應遺失與控制器重啟都必須有明確狀態。
- 不明結果查原工作，不靠重送猜測；技術異常只阻擋必要工具範圍，不取消生活權利。
- 真實登入、語音授權、私人素材或帳務管理不因接入官方MCP而自動獲准。
- 公開AI驗收過程與版本範圍；私人資料／原始生活紀錄／帳號／簽署URL不公開。未做真人、母語、第二實體Windows測試就明示。
