# Windows 操作指南（简体中文）

[English](USER_GUIDE.en.md) · [繁體中文](USER_GUIDE.zh-Hant.md) · [日本语](USER_GUIDE.ja.md)

这是本机 Windows 预览版，数据由用户保管。需要 Node.js 24.19.x、可用磁盘与网络；隔离网页浏览需要 Chrome。这个来源包不包含模型、Codex、帐号或任何既有个体。

## 第一次使用

1. 解压来源包或 clone 到自己的文件夹。不要拿来源包覆盖旧版的 `.private`。
2. 运行「首次设置.cmd」，保留命令窗口。页面上方可选繁中、简中、英文、日文；语言不改变个体内容或生活时区。
3. 第1步检查并安装锁定套件。只安装这份副本的依赖，不下载模型。
4. 第2步选生活时区与大脑。「暂不连接」可以先创建身份。Codex 使用自己的登录与支持的固定版本；Ollama 填本机服务，先自行准备模型。检查服务成功不等于模型具备生活能力。
5. 第3步可选受控 Codex 作品工具。即使大脑是本地模型，也能另外使用此工具，但会把选入的作品与委派内容交给 Codex，并使用帐号额度。接好不会自动给个体权限。
6. 第4步核对并保存，第5步启动、进入控制台。未出生或停止的个体不会因此自行启动。

新安装的生活时区决定每日活动与额度日期。已有数据锁定原时区；缺少时区的旧数据仍为 Asia/Taipei。不得靠修改设置档改换既有生活的时间含义。

## 创建第一个个体

1. 首页按创建新个体，填你选的名字。系统识别码只是数据分隔编号，日常不需使用。
2. 按开始填写出生条件，依八领域24题填写。示例是可模仿的虚构内容，不是标准答案，也不会自动填入。只有自我描述必填，其余可明确跳过。
3. 每页保存进度，再到下一领域。下次选同一个体，按继续填写。另建空白草稿是写另一个方案，不是正常接续方式。
4. 预览出生条件，核对来源与缺漏，再提交审核。审查对象、版本及差异后，Owner亲自批准。查看原版不产生新版本；编辑副本并保存才产生候选。批准身份不会出生。
5. 按下一步进生活设置，依次保存时间、活动轮数与工具权限，再返回出生准备。保存不启动生活、不清零已用量。
6. 大脑未接通时，先保存，返回首次设置，停止这份控制台后设置大脑并重新启动。身份与草稿不需重填。
7. 检查平台。全域停止时先看影响范围，由你决定是否解除。解除不会让其他个体出生或恢复。
8. 最后确认名字、身份、首次活动完整日期、截止与回数，勾选并亲自确认出生。可以现在出生、等待指定时刻才活动；不用等到活动时间才设置。

出生永久留存，停止活动不撤销出生。到期、停止或重启后不会自动补跑。临时加开一次生活请到「管理个体→状态与启停」；日常设置在「时间与额度」。个体与平台模型枠同时生效；网络枠另计，并不精确涵盖模型／TLS等回线开销。

## 阅读与操作

- 「个体来讯」可阅读、回复与标已读；不会因此恢复停止的个体。关闭页面后消息仍保存，这不是背景通知。
- 「工具工作与成品→作品与运行」可看原文、不可覆写的版本及隔离运行结果。程序以文本呈现，这个页面不直接运行任意 HTML。
- 「记忆与纪录」可看记忆版本与原文差异；「生活日志」按生活时区日期投影 B 历史。阅读不调用模型、不消耗个体活动轮数。
- 查看与切换个体不启动生活。各个体的身份、记忆、作品、权限与历史分开。
- 「每日生活报告」已接通本安装。阅读与更新结果不生成；首次设置可选择自动整理，之后在报告设置调整时间与语言。使用本安装的大脑与时区，独立计次但仍共享模型容量。归档只调整显示，不删除资料或启动生活。

## 停止、重新打开与故障

关闭浏览器不等于停止服务。使用本副本的停止入口，重新打开请用「打开开发控制台.cmd」。换浏览器要用首次设置的「拷贝控制台链接」，不要只拷贝网址列。完整链接具控制权，不要分享、截屏公开或放进 issue。

模型繁忙时只有符合安全条件才有限重试；结果不明或已有写入不盲目重做。画面失联先确认服务与有效链接，不要重建个体、重新出生或自行删除租约。错误的详细原始纪录可能包含内部代码；先依白话提示处理，回报时移除身份、对话、密钥及链接。

切换语言会保留可安全接续的未保存输入，不会自动保存到服务器；重要出生确认必须重新勾选。仍建议先保存。原生条件、原始证据与个体内容保留原文，不随语言改写。

## 升级与求助

先停止自己的副本，确认无未收尾工作，做可验证快照。依 [升级与回退](UPGRADE_ROLLBACK.md) 操作，保留最新 `.private`；不能以旧数据库覆盖新历史。未知版本或时区变更会拒绝，不要删除数据来绕过。

目前只优先支持最新版预览，没有固定回复期限。发布后的一般问题依 [SUPPORT](../SUPPORT.md)；安全问题依 [SECURITY](../SECURITY.md) 私人通报。尚未激活的 GitHub 管道不代表能接收数据。四语为工程翻译候选，独立母语审阅与另一台实体 Windows 验收仍待完成。
