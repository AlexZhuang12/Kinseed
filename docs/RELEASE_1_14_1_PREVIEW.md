Owner messages and imported materials retain their stricter rules; credential, local path, private-network, redirect/subresource, permission and budget checks remain. See [privacy boundary](OUTBOUND_PRIVACY.md) and [acceptance](acceptance/PUBLIC_1_14_1.md).

No existing identity, memory, work, history, permission or daily consent is changed. Old requests are not replayed automatically. This is source on main; no new tag or Release is implied. Hosted Windows verification passed. See [the completed acceptance record](acceptance/PUBLIC_1_14_1.md).
