Do not reopen Owner-stopped individuals, add permissions, extend windows, refund usage or make up missed activity. Observe the next naturally authorized round rather than inserting an engineering task into a real individual's life.

Reverting to a source without production binding requires exec selection and no pending background result, B delivery or accounting. A changed local source or damaged backup blocks rollback. Source rollback never overwrites newly appended history with an old database.

These require separate Owner deployment approval; the engineering task only invokes them against independent synthetic fixtures. Do not use the normal cold backup as an automatic disaster recovery tool.
