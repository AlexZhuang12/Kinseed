# Windows 操作指南（繁體中文）

[English](USER_GUIDE.en.md) · [简体中文](USER_GUIDE.zh-Hans.md) · [日本語](USER_GUIDE.ja.md)

這是本機 Windows 預覽版，資料由使用者保管。需要 Node.js 24.19.x、可用磁碟與網路；隔離網頁瀏覽需要 Chrome。這個來源包不包含模型、Codex、帳號或任何既有個體。

## 第一次使用

1. 解壓來源包或 clone 到自己的資料夾。不要拿來源包覆蓋舊版的 `.private`。
2. 執行「首次設定.cmd」，保留命令視窗。頁面上方可選繁中、簡中、英文、日文；語言不改變個體內容或生活時區。
3. 第1步檢查並安裝鎖定套件。只安裝這份副本的依賴，不下載模型。
4. 第2步選生活時區與大腦。「暫不連接」可以先建立身份。Codex 使用自己的登入與支援的固定版本；Ollama 填本機服務，先自行準備模型。檢查服務成功不等於模型具備生活能力。
5. 第3步可選受控 Codex 作品工具。即使大腦是本地模型，也能另外使用此工具，但會把選入的作品與委派內容交給 Codex，並使用帳號額度。接好不會自動給個體權限。
6. 第4步核對並保存，第5步啟動、進入控制台。未出生或停止的個體不會因此自行啟動。

新安裝的生活時區決定每日活動與額度日期。已有資料鎖定原時區；缺少時區的舊資料仍為 Asia/Taipei。不得靠修改設定檔改換既有生活的時間含義。

## 建立第一個個體

1. 首頁按建立新個體，填你選的名字。系統識別碼只是資料分隔編號，日常不需使用。
2. 按開始填寫出生條件，依八領域24題填寫。示例是可模仿的虛構內容，不是標準答案，也不會自動填入。只有自我描述必填，其餘可明確跳過。
3. 每頁保存進度，再到下一領域。下次選同一個體，按繼續填寫。另建空白草稿是寫另一個方案，不是正常接續方式。
4. 預覽出生條件，核對來源與缺漏，再提交審核。審查對象、版本及差異後，Owner親自批准。查看原版不產生新版本；編輯副本並保存才產生候選。批准身份不會出生。
5. 按下一步進生活設定，依次保存時間、活動輪數與工具權限，再返回出生準備。保存不啟動生活、不清零已用量。
6. 大腦未接通時，先保存，返回首次設定，停止這份控制台後設定大腦並重新啟動。身份與草稿不需重填。
7. 檢查平台。全域停止時先看影響範圍，由你決定是否解除。解除不會讓其他個體出生或恢復。
8. 最後確認名字、身份、首次活動完整日期、截止與回數，勾選並親自確認出生。可以現在出生、等待指定時刻才活動；不用等到活動時間才設定。

出生永久留存，停止活動不撤銷出生。到期、停止或重啟後不會自動補跑。臨時加開一次生活請到「管理個體→狀態與啟停」；日常設定在「時間與額度」。個體與平台模型枠同時生效；網路枠另計，並不精確涵蓋模型／TLS等回線開銷。

## 閱讀與操作

- 「個體來訊」可閱讀、回覆與標已讀；不會因此恢復停止的個體。關閉頁面後訊息仍保存，這不是背景通知。
- 「工具工作與成品→作品與執行」可看原文、不可覆寫的版本及隔離執行結果。程式以文字呈現，這個頁面不直接執行任意 HTML。
- 「記憶與紀錄」可看記憶版本與原文差異；「生活日誌」按生活時區日期投影 B 歷史。閱讀不呼叫模型、不消耗個體活動輪數。
- 查看與切換個體不啟動生活。各個體的身份、記憶、作品、權限與歷史分開。
- 「每日生活報告」已接通本安裝。閱讀與更新結果不生成；首次設定可選擇自動整理，之後在報告設定調整時間與語言。使用本安裝的大腦與時區，獨立計次但仍共用模型容量。封存只調整顯示，不刪資料或啟動生活。

## 停止、重新開啟與故障

關閉瀏覽器不等於停止服務。使用本副本的停止入口，重新開啟請用「開啟開發控制台.cmd」。換瀏覽器要用首次設定的「複製控制台連結」，不要只複製網址列。完整連結具控制權，不要分享、截圖公開或放進 issue。

模型繁忙時只有符合安全條件才有限重試；結果不明或已有寫入不盲目重做。畫面失聯先確認服務與有效連結，不要重建個體、重新出生或自行刪除租約。錯誤的詳細原始紀錄可能包含內部代碼；先依白話提示處理，回報時移除身份、對話、密鑰及連結。

切換語言會保留可安全接續的未保存輸入，不會自動保存到伺服器；重要出生確認必須重新勾選。仍建議先保存。原生條件、原始證據與個體內容保留原文，不隨語言改寫。

## 升級與求助

先停止自己的副本，確認無未收尾工作，做可驗證快照。依 [升級與回退](UPGRADE_ROLLBACK.md) 操作，保留最新 `.private`；不能以舊資料庫覆蓋新歷史。未知版本或時區變更會拒絕，不要刪除資料來繞過。

目前只優先支援最新版預覽，沒有固定回覆期限。發布後的一般問題依 [SUPPORT](../SUPPORT.md)；安全問題依 [SECURITY](../SECURITY.md) 私人通報。尚未啟用的 GitHub 管道不代表能接收資料。四語為工程翻譯候選，獨立母語審閱與另一台實體 Windows 驗收仍待完成。
