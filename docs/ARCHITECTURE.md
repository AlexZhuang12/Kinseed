# Windows 開發架構與資料保護

開發入口 `scripts/development.mjs` 使用目前V1.2核心及控制台，但獨立管理啟動、設定與資料。它不調用歷史遷移、原生條件匯入、Codex預檢、報告啟動或既有單例埠。

## 啟動順序

讀取工作目錄標記 → 驗證設定 → 檢查路徑與連結 → 核對私人資料標記 → 啟動本機空平台 → 將Owner連線存入私人資料區。已有未知內容的資料夾不接管，同一資料庫已有管理程序時拒絕第二次啟動。

模型執行器預設停用；明確啟用第2版Codex設定並通過預檢後，生活與獨立請教共用src/brain接口，工具仍經原MCP門核對。模型接入不改任何個體的工具權限、身份或生活授權。報告用途也使用同一契約，但不啟用報告排程。

## 設定與相容性

產品版本目前沿用1.2.0，平台與個體SQLite格式仍為12；設定支援第1版停用、第2版Codex與第3版本地接頭，私人資料標記維持第1版。容量仍為記憶60條、計畫20條、提交總量20,000字元，不使用舊20／10程式還原擴充資料。

`source-baseline.json`記錄程式來源雜湊。獨立入口、空白初始化、報告導航與前端組裝是本階段的變更；其餘生活核心沿用既有來源。檔案允許清單控制套件候選內容，私人資料另受忽略規則保護，但公開發布仍需完整審查。

## 升級與回退

本版沒有遷移正式資料，也沒有部署至既有控制器。停止本開發版即可停止使用；刪除程式前應另行保留 `.private`及本地設定，不能用測試資料覆蓋其他環境。

未來正式升級必須先確認工作收尾，使用一致性備份，檢查身份、出生、原始歷史鏈與資料格式，再由Owner決定恢復。複製正在寫入的SQLite主檔不等同於一致性備份。資料搬移只能有一個活動控制器，不能讓同一個體在兩處同時生活。

## 大腦接口與下一階段

模型執行器已統一開始、工具觀察、完成、取消、逾時、未知結果與用量，詳見BRAIN_INTERFACE.md。Codex接頭內部仍由CLI管理工具往返；Kinseed負責租約、授權與交易，不能用模型文字當成工具成功或取消確認。本地接頭的對話與工具循環已完成合成驗證，真實模型仍待選定與實測，見LOCAL_BRAIN_PHASE_03.md。Codex委派作為手腳屬於另外的工具能力，尚未接入，不與本階段Codex作為大腦混淆。

## 受控委派更新

受控工具執行者已在本候選接入，見 CODEX_TOOL_INTERFACE.md。父大腦經原生活MCP呼叫delegate_codex；子Codex只取得另一個獨立短效代理，不取得父cycle能力、身份、記憶或Owner控制。原作品工具仍核對同一個體的授權與租約；未知工具或交易收尾會保留原worker。上節「尚未接入」為此前階段語境。
