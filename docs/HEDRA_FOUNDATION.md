# 本地 Hedra 工具使用說明

適用Windows預覽控制台1.6.1-preview.1。本次更新保留身份、出生、記憶、歷史、每日安排、時段與已用額度。新Hedra媒體權限預設關閉，不代表三個個體已能使用。

## 從哪裡操作

從本份安裝的「開啟開發控制台.cmd」或npm run open開啟目前的Owner連結，進入「工具與材料」，選個體後按「Hedra媒體工具」。舊瀏覽器分頁請重新開啟，以取得重啟後的新Owner連結。

1. 「唯讀檢查Hedra連線與餘額」只查目前登入、計費模式與點數，不生成。
2. 「允許此安裝使用Hedra真實連線」與風險確認屬於全安裝共用連線。Owner接受共用OAuth計費來源可能被其他客戶端更改後保存；系統仍在每次送出前檢查credits與工作區。這不開啟個體媒體權限或生活。
3. 不需要填寫訂閱日期、續訂日或原始配發量。唯讀檢查直接讀取MCP可用點數；可選擇設定Owner保留額（預設0，既有保留額保持）。系統不推測訂閱是否有效，服務拒絕、登入失效、餘額不足或無法連線時明示實際情況。
4. 為各個體選擇圖片、影片、聲音權限及累計使用／單件上限，保存後才生效。累計包含歷史已用及暫留點數，不能藉由日期、重啟或續訂清零。餘額增加不會自動提高Owner核准上限。各個體上限不是遠端點數的保證分配；每次提交仍須通過即時餘額、Owner保留額、所有暫留工作及單件上限。
5. 個體仍須有有效生活授權才能提出新工作。影片及音樂須明確指定長度，最多60秒；聲音目前指音樂，不包含語音、聲音複製或音效。

本次正式更新沒有代Owner設定三人的Hedra累計上限與媒體權限、開啟連線或媒體權限。獨立測試版的350／500／350與800保留額僅為已討論的配置示例，不會當成正式帳目搬入。

## 如何理解狀態

- 估價：沒有生成、沒有扣點。
- 已排入：本地先暫留點數，仍可能因權限、價格或生活條件改變而不送出。
- Hedra製作中：已保存遠端工作編號，受理不等於完成，也不等於費用已確認。
- 已完成：查回原工作完成並核對實際cost／currency後才結算。
- 提交結果待核對：可能已在遠端製作，保留暫留，不重新送出。
- 費用待核對：不假設免費或退款；Owner可按「重新查詢原工作（不重做）」。

已送出的工作在生活結束、關閉連線或控制器重啟後仍可查原工作收尾；不增加LLM輪數、不取消未來每日安排。遠端異常只影響必要的付費操作範圍。

目前只保存成果狀態與metadata，沒有自動下載／播放器／素材上傳。不能讓個體讀取Owner的全Hedra素材庫、金鑰、工作區切換或計費管理。Hedra素材外傳不包含在原材料的大腦分析同意中。

## 計費與驗收邊界

本接頭使用既有官方Hedra OAuth，不複製金鑰，不啟動新的大腦模型turn。政策標示oauth_credits_checked、fixed=false，表示檢查而非供應商端鎖定。本地額度不控制Owner或其他客戶端的花費；Owner已選擇自行控管這項風險。

本地正式來源的受控MCP、權限、估價、唯一提交、原工作查詢、帳本及B鏡像已用合成個體完成一次真實Hedra圖片測試，實際1 credits。完整695 Node及395四語UI檢查通過。故障注入使用合成供應商，不宣稱已驗證供應商斷線、退款、exactly-once或免除未知風險。未做人類／母語／第二實體Windows驗收。

控制器的「停止」是Owner停用生活的動作，不能把它當成只關視窗。維護由已授權的安全關閉流程處理，不自行停用或恢復個體。回退只回退來源，不以舊資料庫覆蓋新歷史；付費帳本與原始收據要保留。

## 1.6.1 記帳相容性

舊訂閱週期、原工作與帳本事件保持原樣，只停止把日期與原配發總量當作新工作的先決條件。所有歷史工作納入累計額度，既有Owner保留額繼續保護，未確認結果仍不自動重送。技術異常只阻擋必要的Hedra付費操作，不取消個體未來每日生活。API沒有證明訂閱失效時，介面不把一般連線錯誤說成過期。
