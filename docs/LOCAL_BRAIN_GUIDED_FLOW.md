# 本地大腦流程核對候選

此版本只增加可選 `adapterOptions.toolProtocol:'guided'`，舊 native、schema、staged 均保留。沒有自動啟用模型、下載、換模或部署，沒有資料結構遷移。

## 依序處理的四件事

1. **指令一致性**：保留原任務為系統訊息原文；執行協定不覆蓋身份、治理與明確的保留／等待要求，未指定部分才自主。記憶階段不再同時說「依原要求保留」和「要不要保留自行決定」。decision 使用文字欄位，不依選項排列預設答案；continue 不得同時帶 wait_ms，wait 必須帶有效 wait_ms。矛盾時只請同一模型自行修正未提交草稿一次，系統不替它選答案。
2. **現在與歷史分開**：`current_state.a.version` 是讀到的當前版本；`historical_snapshot` 保存原記憶／計畫／上輪結果，明示不代表當前狀態。原文不改寫；完整身份、來源、授權與閱讀入口保留。僅在確認值相同時省略重複身份索引，另記原始與呈現情境。
3. **有限重新判斷**：完成的本地唯讀操作明確回報錯誤後，最多兩次讓模型重新選行動；原未完成清單作參考，不盲目接著執行。已失敗的相同參數與已成功的相同寫入仍停止。寫入、外部操作及未知結果不走這條自動恢復路徑。所有重新判斷共用原 120 秒、16 工具、17 模型回覆，不延長、不增權。
4. **操作敘述核對**：系統由實際執行產生當輪收據；模型另填 execution_claims，逐一列 receipt_id、tool、outcome，含失敗。不存在、工具不符、結果不符或漏列實際操作會被拒，最多自行修正草稿一次，沒有執行中的工具被重做。通過後才使用原 commit_cycle 提交模型原文。

## 可保證與不能保證

收據核對只證明某工具確實執行並回報 success／error，不等於任務完成，也不證明每句自然語言都正確。`execution_verification.narrative_verified` 固定為 false；提到當輪未執行工具的記憶／總結另有 UNEXECUTED_TOOL_MENTION 警示。這可能是回憶、意圖或錯誤敘述，警示本身不是完整語意判定。

不因警示替個體改寫、補齊或刪除記憶；既有主觀記憶也不被升格為系統事實。完整未提交草稿、驗證錯誤、修正稿及真實收據都留在私人依據。成功提交的意思是交易已提交，不能顯示成所有工作已成功。

請求編號與記憶 expected_version 為系統綁定；作品的 expected_version 仍由模型依實際作品資料選擇，不混用成記憶版本。所有內容與來源編號由模型產生，最終仍經原 MCP 驗證。

## 驗證及使用限制

單元／合成 HTTP 測試不是語言模型能力證據；真實 Qwen3 使用同一既有模型、自己的程序／私人模型副本／埠，不使用共用聊天推理服務。每次觀測都必須檢查正式生活與共用聊天優先，以及 RAM 安全保留。

目前是工程驗證候選，真實改善與未解問題以本次交付報告為準，不因程式回歸通過就採用正式生活。完整背景、長記憶、更多工具及其他模型需分別驗證。

## 回退

確認候選工作完整收尾後，移除 guided 選項即可回到原接頭；如需來源回復，使用本次 source-before 清單。保留私人資料與全部失敗證據，不以舊資料庫覆蓋新歷史，也不操作其他模型服務、恢復過期生活或推定新權限。正式來源未修改。

內容階段另在提示明示同一工具Schema欄位，不只依賴機器格式。此調整的真實對照只顯示部分內容改善，仍會多編內容；不代表全面成功。未提交草稿的全部驗證問題一併回報，仍不代填。真實模型驅動腳本有結果保護，不能當狀態查詢重跑。
