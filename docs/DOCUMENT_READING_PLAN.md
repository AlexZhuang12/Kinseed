# 自製文件讀回與實際頁面預覽工程計畫

D01已保存PDF／Word／Excel原檔讀回 → D02受控PDF指定頁PNG及MCP影像 → D03Owner翻頁介面與四語 → D04隔離、權限、大小、SHA、期限及取消收尾 → D05合成與真實模型驗收 → D06正式無工作時冷備份、只來源更新、每日安排與資料保留核對 → D07本機交付與操作文件。

本輪沿用既有documents／vision權限，沒有新增自動授權。原PDF不重製、不移到另一資料庫；身份、出生、記憶、歷史、生活時段、用量與其他權限保留。原1.5.0每日授權與執行健康分離政策保留。共用聊天與Ollama不操作。本輪未授權GitHub推送。

驗收以合成個體為主：製作後讀回、舊ID讀回、實際頁面／字型、翻頁與個體切換、跨個體拒絕、材料同意不可繞過、文件與視覺權限撤回、不支援模型明示、檔案損毀、頁碼與資源界線、取消收尾、原時段與額度保留。另用真實Codex/MCP單輪驗證模型自製PDF讀回、影像辨識與自行提交記憶，不補寫內容。
