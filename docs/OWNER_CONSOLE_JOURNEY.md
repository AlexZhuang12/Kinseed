# 工具操作路徑：介面候選 1.12.0-ui-preview.1

這份候選先供獨立試用，尚未部署正式控制台，也未發布。

從「工具與材料 → 使用總覽」開始：

1. 選擇要管理的個體，核對頂端作用對象。
2. 準備工具：先查看連線狀態，遇到帳號資料按「操作說明」。共用帳號設定與個體設定分開。
3. 開放能力：在「工具權限」按用途勾選，再明確保存。勾選是草稿；以伺服器讀回的已生效狀態為準。
4. 交材料、看成果，或到相應的郵件／音訊區核對待批准內容。

保存是綠色主按鈕；放棄是次要按鈕，並同時以文字顯示草稿與已生效狀態。變更權限不等於啟動生活，等待工作收尾也不等於取消每日安排。

## 各區的用途

- **外部連線**：Gmail用戶端與只寄送授權。待批准郵件提供往返入口；連線不代表同意寄信。
- **雲端空間**：目前未接入可用服務，明示不能連線；歷史欄位只供查看，不能把保存表單當成實際接入。
- **Hedra**：先處理共用連線與Owner保留額，再設定所選個體的媒體能力與累積／單件額度。模型目錄只是選看資訊，不是模型授權清單，也不會生成或扣點。
- **聲音理解與比較**：依序是Owner專用服務、所選個體的連線與權限、逐份音訊核對與結果。技術路徑與原始資料收在進階區。從服務帶入端點只填草稿，不自動保存或開權限。

## 獨立試用的邊界

入口是候選根目錄的「開始預覽.cmd／開啟預覽.cmd／停止預覽.cmd」。只包含三個虛構試用個體。頁面上的Gmail、Hedra點數與Whisper狀態為合成示例，不能當作真實帳號連線證據。

請使用「填入預覽用戶端示例」「填入預覽檔案示例」練習。預覽不接受真實Gmail密鑰、不寄信、不生成扣點、不啟動真實模型，也沒有正式個體資料。音訊示例只練習逐份批准，不會送出辨識。

預覽的模擬入口與一般正式啟動入口分開，避免從預覽誤啟真實服務。正式整合與部署另行授權。
