# 1.12.0-preview.1

Public source alignment with the 1.12.0 local feature baseline. New installations use their own empty private runtime and first-setup entry; local operational data and authorizations are never shipped. This updates the repository source; a GitHub Release/tag is not created by this push.

## Changes since 1.6.1

- Bounded tool-output handling and recovery retain Owner daily-life consent while isolating failed operations.
- Hedra model catalog/specification queries, saved original media and viewing, reference-image continuation, public-voice speech and sound effects with separate scoped permissions, credit reservations and uncertain-submission reconciliation. Availability depends on the connected account and provider; no automatic paid retries.
- Local film projects: scoped artifacts, assembly, audio tracks, subtitles, technical inspection and version comparison. Technical measurements do not imply artistic evaluation.
- PDF headings and page-boundary handling, bounded multi-page preview queue, generated-document readback. Original existing works are not rewritten by upgrading.
- Replaceable audio-understanding interface, local Whisper service management, dialogue transcription, silence guards and suspicious-result notices that retain the model's original text. No model weights or automatic downloads; no claim of emotional or music comprehension.
- Four-language guided console, grouped permissions, explicit saved/draft states, linked account-setup instructions, Hedra and audio workflows, pink visual hierarchy and category headings above action buttons.

## Acceptance and limitations

The matching local source candidate passed 874 Node tests, 848 browser checks across 35 scripts, and 54 synthetic update/rollback checks. These are earlier local candidate evidence, not counts of a fresh public run. Public-source verification and hosted CI are recorded separately in docs/acceptance/PUBLIC_1_12_0.md. The version-specific UI assertion now uses the runtime version constant so it verifies the public version rather than a local suffix.

Acceptance is AI-executed project self-acceptance. Owner supplied first-party interface feedback; no independent third-party human, native-language review or second physical Windows acceptance was performed. Historical provider-generation and speech tests do not imply new paid tests for this push. The public verification runs use synthetic individuals and mock providers, without private identities or new generation/email charges.

Whisper CPU inference may slow the computer. Service start requires resource checks and Owner setup; it is not automatically started by installing or granting hearing permission. Accounts, material consent, per-item approvals and quotas remain required. Cloud storage remains settings-only without an implemented provider.

## Installation

On supported Windows with Node 24.19.x, clone the repository and run the first-setup CMD (首次設定.cmd). Follow the four-language guide linked from README. Existing installation owners should back up and verify compatible source updates; do not replace current history with an older database.
