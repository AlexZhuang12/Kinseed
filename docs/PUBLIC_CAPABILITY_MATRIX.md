# General installation capability matrix

| Capability | Source status | Required user action / limit |
|---|---|---|
| Identity drafting, review and first birth | Available in general mode | Explicit Owner approval and birth; no imported private identities |
| Daily life and schedules | Available | Selected brain, life window, budgets and explicit consent; Owner stop is respected |
| Four-language console and report page | Available | AI-authored translations; native review not performed |
| Manual reports, versions and exact source evidence | Available | Selected brain for generation; reading never generates |
| Automatic report schedule | Available, explicit opt-in | Installation time zone; selected model capacity and independent report limits |
| Archive / restore visibility | Available | Stopped, settled and daily disabled to archive; restoring does not start life |
| Network and three public-data services | Available subject to permission | Network budgets, public-network boundaries and actual provider availability |
| Materials, documents, projects and image reading | Available subject to permission | Material consent, selected model capability and prepared local assets |
| Codex controlled tools | Available subject to permission | User's own login and installation-level enablement; no arbitrary host shell |
| Gmail drafts and sending | Connection and approval flow available | Own OAuth; send-only scope, explicit approval of recipient/content/attachments |
| Hedra creation, retrieval and accounting | Available subject to permission | Own connection, live billing mode, budgets and generation authorization; provider limits apply |
| Local audiovisual processing | Available subject to permission | Prepared dependencies and sufficient hardware; bounded workspace |
| Audio understanding / Whisper | Interface available, installation required | Own service/model, resources and permissions; no weights or live sessions distributed |
| Cold backup and verification | Available | Controller closed and work settled; includes reports |
| Upgrade / source-only rollback | Available for unchanged dependencies | Reviewed source, verified cold backup, receipt; does not restore old DBs |
| Cloud-storage service | Settings only | No unnamed provider connection is claimed |
| Cross-installation synchronization / shared total budget | Not implemented | Same login does not synchronize data or coordinate local quotas |

Mechanism acceptance uses synthetic individuals and providers. It does not qualify every external provider, every local model or every hardware combination. Previous real-provider evidence is historical and is not counted as a new test in this version.
