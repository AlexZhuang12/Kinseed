# 控制台 1.12 操作說明

本版整合操作導引、粉色視覺與分類導覽。新安裝先執行「首次設定.cmd」，再由導引啟動自己的控制台；不附帶任何既有個體或帳號資料。

工具與材料依四個分類呈現：開始、工具設定、材料與成果、Owner處理。分類標題在上、按鈕在下，分類本身不是需要解鎖的功能。

保存採深玫瑰色，查詢採淡紫色，次要操作採輕框。勾選是草稿，以讀回的已生效狀態為準；保存權限不等於出生、啟動生活或取得新的生成批准。等待工作收尾不取消每日生活授權。

Gmail與待批准郵件提供往返入口，欄位附官方找值說明。雲端尚未實際接入，不能把預留表單當作已能同步。Hedra共用連線、Owner保留點數與個體能力額度分開；模型查詢不是授權，也不生成。

聲音頁分成Owner專用服務、個體連線與權限、逐份音訊批准。帶入服務網址只填草稿，不自動保存或開權限；既有Whisper路徑、資源門檻、狀態確認與不重送防護保留。

正式版不包含獨立預覽的合成帳號、模擬餘額、示例按鈕或假模型狀態。正式連線的查詢與保存操作會作用於實際設定，寄信、生成與音訊分析仍須各自原有授權。

程式更新與生活、工具授權分開。更新不得重置額度、補跑過期時段或自動新增工具權限；Owner明確停止或變更仍以最新操作為準。舊資料升級前應備份與驗證，不以舊資料庫覆蓋新歷史。
