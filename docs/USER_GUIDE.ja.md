## 1.5.1

ツールと資料で個体を選び、プロジェクトと成果からPDFページのプレビューを開きます。保存済みの元ファイルを描画し、作り直しません。個体の切り替えでプレビューを消去します。個体はread_documentで自作PDF・Word・Excelを読み返せます。document_viewには既存の文書・画像権限と検証済みの画像対応接続が必要です。文字の抽出だけではレイアウト確認になりません。既存文書の移行は不要です。

## 1.5.0

毎日の生活への同意と実行状態は別です。Ownerが明確に停止した場合だけ毎日の許可を取り消します。接続障害、時間切れ、正常な再起動、設定の保存では許可を取り消しません。必要な操作を保留し、理由を表示します。作業終了後は毎日の生活を停止せず権限を保存できます。元の時間・使用量・分離の制限は維持されます。

# Windows 操作ガイド

[繁體中文](USER_GUIDE.zh-Hant.md) · [简体中文](USER_GUIDE.zh-Hans.md) · [English](USER_GUIDE.en.md)

ローカルで使うWindowsプレビュー版です。データは利用者自身が保管します。Node.js 24.19.x、ディスク領域、ネット接続が必要です。隔離ウェブ閲覧にはChromeを使います。配布ソースにモデル、Codex本体、アカウント、既存個体のデータは含みません。

## 初回設定

1. ソースを展開またはcloneします。既存の `.private` を配布ファイルで上書きしないでください。
2. `首次設定.cmd` を実行し、コマンド画面を開いたままにします。上部で繁体字、簡体字、英語、日本語を選べます。言語の変更は保存内容や生活のタイムゾーンを変えません。
3. 第1段階で固定版の依存パッケージを確認・導入します。このコピーだけに導入し、モデルはダウンロードしません。
4. 第2段階で生活のタイムゾーンと大脳を選びます。未接続のままアイデンティティの下書きを試すこともできます。Codexは自分のログインと対応CLIを使います。Ollamaは自分でモデルを準備し、ローカルサービスを選びます。接続確認は生活能力の検証ではありません。
5. 第3段階のCodex作品道具は任意です。ローカル大脳でも利用できますが、明示した委任作業と選択した作品をCodexへ送り、アカウント枠を使う場合があります。接続だけでは個体への利用許可になりません。
6. 第4段階で確認・保存し、第5段階で制御画面を起動します。個体が勝手に誕生・再開することはありません。

新しい環境では選んだ生活タイムゾーンで日々の時間と枠を計算します。既存データは元のタイムゾーンを保持し、タイムゾーンのない旧データはAsia/Taipeiです。設定ファイルの変更で既存の予定を読み替えないでください。

## 個体を作り、誕生を確認する

1. ホームで個体を作成し、名前を入力します。内部の識別番号はデータを分離するためのもので、名前とは別です。
2. 出生条件を記入します。8領域24問に架空の例を参考に回答できます。例は正解ではなく、自動入力もしません。自己説明のみ必須で、他の質問は明示的に飛ばせます。
3. 各ページの進捗を保存して次へ進みます。再開は同じ個体を選んで「記入を続ける」を使います。別の空白下書きは別案を作るためです。
4. 条件、出典、不足をプレビューして審査に提出します。対象、版、差分を確認し、自分で採用を承認してください。原版の閲覧では新しい版を作らず、コピーの編集・保存で候補を作ります。承認しても誕生しません。
5. 次への案内に従って生活時間、モデル回数、道具の権限を保存し、誕生準備に戻ります。保存で起動や使用量の初期化はしません。
6. 大脳が未接続なら、先に保存し、初回設定へ戻ってこの制御画面を停止し、大脳を設定して再起動します。アイデンティティと下書きの再入力は不要です。
7. 全体の状態を確認します。全体停止中は影響範囲を読んで解除を判断してください。解除で他の個体は誕生・再開しません。
8. 名前、アイデンティティ、初回活動の完全な日時、終了時刻、回数を確認し、自分で確認欄を選んで誕生を確定します。今誕生し、指定時刻まで活動を待つことができます。

誕生は永久に記録し、停止しても取り消せません。期限切れ、停止、再起動後は自動で埋め合わせません。一度だけの臨時生活は「個体を管理→状態と開始・停止」、日常の時間は「時間と枠」で操作します。個体と全体のモデル上限は両方適用します。ネット枠は別で、モデル通信やTLS等の全通信を厳密には計測しません。

## 記録と成果を見る

- 「個体からの伝言」で閲覧、返信、既読にできます。これだけで生活を再開しません。閉じても保存されますが、背景通知ではありません。
- 「道具の作業と成果→作品と実行」で原文、変更不能な旧版、実際の隔離実行結果を見られます。制御画面で任意のHTMLは実行しません。
- 「記憶と記録」で記憶の版と原文差分を見られます。日誌は生活タイムゾーンの日付でB履歴を表示します。閲覧にモデル枠は使いません。
- 個体の切り替えは閲覧だけです。アイデンティティ、記憶、作品、権限、履歴は個体ごとに分離します。
- この開源プレビューでは毎日のLLM日報サービスは無効です。無効なボタンは利用可能を意味しません。

ブラウザーを閉じてもサービスは止まりません。このコピーの停止入口を使い、再表示は `開啟開發控制台.cmd` を使います。別ブラウザーでは初回設定のリンクコピーを使ってください。完全なリンクは操作権限を持つため、他者やissueに公開しないでください。

モデルの一時障害は安全が確認できる場合だけ有限回再試行します。結果不明や書込済みの作業を無条件で再送しません。切断時はサービスとリンクを確認し、個体の再作成、再誕生、処理権の手動削除をしないでください。詳細な原記録には内部コードが残る場合があります。案内の回復手順を使い、報告時はアイデンティティ、対話、認証情報、リンクを除いてください。

言語切替時は対応する未保存入力をローカルで引き継ぎますが、サーバーへ自動保存しません。誕生の最終確認は選び直します。可能なら先に保存してください。個体と証拠の原文は翻訳しません。

## 更新と相談

自分のコピーを止め、未完了作業がないことを確認し、検証できるスナップショットを作ります。[更新と回退](UPGRADE_ROLLBACK.md)に従い、最新の `.private` を保持してください。古いDBで新しい履歴を上書きしません。未知の版や既存タイムゾーンの変更が拒否されても、資料の削除で回避しないでください。

最新版プレビューを優先し、回答期限は保証しません。公開後の一般相談は[SUPPORT](../SUPPORT.md)、非公開の脆弱性報告は[SECURITY](../SECURITY.md)に従ってください。未有効のGitHub窓口にはまだ送れません。翻訳は工程上の候補で、独立した母語確認と別の実機Windowsでの確認は未完了です。
