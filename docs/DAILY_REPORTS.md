# 每日生活報告

從生活控制台進入「每日生活報告」。報告依本安裝時區的日期整理，與個體的生活、身份與作品分開保存。

1. 選擇日期：已有成功報告時直接閱讀，不會因選日期而生成。
2. 需要新版時按「整理這一天的報告」：會使用獨立報告模型額度，另存一個新版本。
3. 查看整理狀態：顯示等待生活空檔、整理、查核、成功或失敗。整理中不必重複提交。
4. 閱讀下方報告，展開「查核這段的原文依據」核對引用；可再展開完整來源資料。

「更新結果（不重新生成）」只讀取最新保存狀態，不呼叫模型。歷史版本可在「版本與整理紀錄」中選擇；按更新結果會回到最新完成版本。

## 沒有出現新報告時

- 等待生活空檔：原生活優先，報告等待，不會替個體停止生活。
- 引用檢查失敗：引用必須逐字出自指定來源。換行、引號、反斜線以解碼後的原文檢查；不合併不同欄位、不模糊匹配、不補寫模型引用。
- 內容依據不足：即使引用正確，另一輪模型仍可能認為摘要誇大或依據不足。系統會將有效核對意見交回模型，對該篇短文最多修訂一次，使用同一份原始資料，再逐字檢查與獨立核對；不由系統代寫文字或補來源。仍未通過就不保存為成功版本，舊成功報告保留，畫面顯示原因。個體自述與計畫不等於系統已獨立查證成果。
- 連線中斷：先更新結果核對是否已受理，不要反覆提交。系統不因畫面讀取失敗而自動重送生成。

報告工作仍有原本的每日用量、單次呼叫與等待上限。自動整理時間與語言可在每日報告設定調整，須由Owner明確開啟，並保持電腦與控制器運作。引用檢查與獨立模型核對可減少錯誤，不是外部事實認證。

個體選單管理收在使用說明底部。封存選項與報告生成是不同操作；封存影響日常選單、生活日誌及新報告，保留原資料與歷史，不會代替Owner停止生活。

公開版候選 1.14 已接通同一安裝的報告及封存。使用本安裝選定的大腦；每日60次／每份24次為報告獨立呼叫上限，仍與模型帳號共用容量。首次設定可選擇每日自動整理；已有資料後請在控制台調整。詳見 [完整安裝指南](PUBLIC_INSTALL_1_14.md)。
