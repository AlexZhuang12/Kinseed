# 正式切換方案（尚未執行）

本文件是候選版部署的前置方案，不授權停止、重啟、恢復生活、增加權限或發布。工具獨立候選不能直接整目錄覆蓋既有安裝。

## 切換前

1. 核對最終來源包SHA、依賴鎖檔、驗收摘要及已知限制；先在另一個獨立staging合併正式整合入口與候選差異，使用合成資料重驗，不連正式runtime。
2. 保留既有整合控制台、日報、封存管理、每日授權與操作入口；核對所有變更檔與新增檔。來源與鎖檔須一致，不以候選的開發package.json覆蓋本機整合入口。
3. 正式整合版的版本字串、啟動入口及狀態核對有自己的綁定；部署工程須一致更新並重驗啟停、狀態、日報與新工具導航，不能只複製工具頁面。
4. 部署窗口、當時生活影響與恢復範圍須由Owner批准。優先等待既有工作自然結束且沒有worker／租約／工具程序；不為維護自行中斷有效生活。

## 執行窗口（取得另外授權後）

1. 再核對正式狀態與授權；有未收尾或未知外部工作即暫停切換。記錄身份、出生、A版本、原B前綴與鏈、作品、日報、草稿、設定、權限、時段、截止、每日安排及已用額度。
2. 經正式安全關閉入口等待程序退出，建立一致冷備份並校驗。不得以關閉瀏覽器當作控制器已關閉。
3. 只部署已合併驗證的程式與依賴。不複製候選.private、合成個體、測試出生、記憶、授權、OAuth或日報至正式安裝。
4. 新工具欄位預設關閉；新表按相容方式建立，不覆寫原state／事件／收據。保留既有身份及歷史，不能重新出生或重設額度。
5. 啟動後先維持停止並唯讀核對全部資料與服務。控制器重啟會撤銷每日安排，不能偷偷復活先前授權；若Owner希望重新開啟，另以明確對象及範圍的授權執行。

## Gmail與新能力

獨立驗收的Gmail憑證不自動搬入正式環境。Owner另選正式連線及個體權限；有連線也不構成寄信批准。每封仍須核對對象、內容及附件。模型不持有OAuth或Owner批准接口。

## 回退

切換失敗先保持停止、收尾已知程序，再恢復相容程式與依賴。沒有新寫入時可使用校驗冷備份做災難復原；已有新資料時不得直接覆蓋舊DB，須保留新資料並檢查新表／事件的向後相容性。不能藉回退復活過期授權或還原已用額度。

有未知外部寄送時先核對實際結果，不能以回退重送。任何不一致都保留具體證據並阻擋恢復，不宣告切換成功。

GitHub更新是另一個決策，不包含在本機部署中。本輪只完成獨立交付，不執行正式切換。
