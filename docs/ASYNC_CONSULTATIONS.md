# 可稍後領取的獨立諮詢

`consult_llm`向目前設定的模型另開獨立對話，只傳這次問題，不提供個體完整身份或記憶，不使用工具。受理立即回傳job_id；個體可繼續其他活動，後續有效生活輪次用`consult_status`查看待辦或指定job_id領取原始回答。等待與失敗不取消每日安排，也不封鎖未來的新問題。

每輪最多提出一次，每個體最多一個待處理工作，整個控制器同時執行一個背景諮詢。接受時預留並計入原個體與平台模型次數；失敗不退還、不清零或增額。相同請求ID不重送，問題待處理時不建立重複工作；回答不是已查證事實，也不會自動寫入個體記憶。

諮詢有獨立3分鐘上限，不因原本活動輪次交接而取消；已接受工作可收尾，但不因此增加個體生活時段或喚醒個體。Owner停止／改設定會取消未送出工作並要求執行中工作收尾。控制器關閉先確認背景程序退出，再關資料庫；未確認退出時阻擋關閉，不殺未知程序。

重啟後不重送queued/running工作：保留原問題與額度，標明未送出或中斷。失敗不會自動改成成功、重問或用其他模型補答。若本機程序退出仍未確認，只保留該諮詢資源的位置，不擅自啟動重疊工作；不取消每日生活授權。

舊版consult_llm不明結果限制須經Owner專用核對入口，查到原週期失敗、原模型退出、同一個體的實際諮詢證據且沒有回答後才解除。只移除consult_llm限制；不清除其他工具／身份／安全限制，不重送舊問題、不補寫答案或記憶，原事件與已用次數全部保留。
