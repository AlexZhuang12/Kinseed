# 第3階段：本地大腦接入前盤點

目前狀態：依Owner後續選擇，完成本地接頭與合成驗證；模型選擇與下載留待下一次討論。未安裝本地推理程式、下載模型或執行真實本地推理。預設大腦仍停用，Codex接頭保持相容。

## 已實作與操作

`src/brain/ollama-adapter.mjs`提供Ollama本機HTTP協定接頭；這是服務接口選擇，不是選定模型。`local-http.mjs`負責受限API與資料上限，`mcp-client.mjs`以本候選自己的Node程序執行既有MCP。`runtime.mjs`依明確設定建立Codex或本地接頭，不自動換來源。

先在本目錄執行`npm run brain:resources`唯讀看資源。第3版範例在`config/local-model.example.json`，`enabled:false`且模型名稱只是`owner-selected-local-model`佔位，不會下載或替Owner選模型。目前請保留停用；未來完成模型選定及實測安排後，才在本候選停止時另存為`config/development.local.json`、填入實際本機模型完整名稱與合適上下文，明確啟用。`npm run check`只核對服務及模型資訊，不發推理。`npm run brain:disable`保留原接頭與模型設定，只停用；不改資料或恢復生活。

上下文／輸出預算只是測試設定，不代表目前硬體能承擔。服務只接受`127.0.0.1`、獨立HTTP埠，不接受外部位址、URL憑證、重新導向或正式控制器埠。不繼承Cookie或Owner／cycle token給模型API。只用version／tags／show／chat，不pull、不login、不更新、不卸載他人的模型。

每輪先核對已安裝模型摘要、文字／工具能力及宣告上下文；工具往返前重驗摘要，變動停止。完整訊息與工具按保守UTF-8位元組預算檢查，不自動切除內容；不同真實模型的tokenizer、截斷行為及長情境可靠度仍須真實驗收。`think:false`且不保存thinking欄位；實際模型是否正確遵守仍待實測。

生活先get_context，再以既有MCP工具往返，單獨commit_cycle成功才完成；原16次工具／2分鐘／權限／記憶交易不放寬。一般文字不能當作已保存記憶。請教與報告沿同一設定，但不給工具。對諮詢的描述改成「另開獨立對話」，不暗示它是另一種更強模型；使用本地模型時仍會消耗本機資源。

## 已通過的合成範圍

測試HTTP服務明示`SYNTHETIC-PROTOCOL-NOT-A-MODEL`，不是LLM。真實Node MCP程序、Kinseed權限檢查與SQLite用於合成個體：兩輪身份／記憶延續、筆記追加、另一個未出生個體保持不變、獨立MCP程序退出及worker釋放。另測未授權筆記、未先讀身份、未提供shell、模型摘要變動、已保存筆記後未提交、Owner停止後不執行模型建議，以及取消結果未知時保留worker／租約。

單元協定涵蓋外部／正式埠拒絕、cloud來源拒絕、無模型／工具／上下文、重新導向、純文字工具拒絕、缺用量、截斷／格式／不完整回應、斷線、超量、重複編號、逾時／取消、舊版設定相容、明確停用、無下載及無自動fallback。瀏覽器分別驗證停用、模型缺漏、合成服務預檢可達，均明示真實推理未驗證，不自行出生。

## 收尾限制與回退

收到`done:true`且來源一致才視為本次推理已回覆；取消時停止新工具，最多等待10秒收尾回覆。只有HTTP斷線、無完成回覆或連線被取消時，無法確認外部服務是否仍計算：`local_exit_confirmed:false`，沿既有控制器保留worker／租約，追加`brain.settlement_unconfirmed`，超過既有收尾期限顯示阻擋。MCP程序退出不等於模型計算退出。

不能用`api/ps`的模型常駐清單推論某個請求已取消，不能殺掉Owner或其他程式的共用服務。已知未知結果目前須保留資料後診斷，沒有自動解鎖；未來模型與服務選定後，需驗證請求級取消或由本候選持有的獨立服務收尾，才能評估長期使用。合成測試的最終settlement注入只為測試清理，絕不作為正式停止證據。

回退先停用並確認本候選所有工作已收尾，再改回第1版停用或第2版Codex設定；設定切換不批准、不出生、不恢復。不以舊DB覆蓋任何生活史，不操作其他環境。

## 這一階段的責任

讓本地模型成為可替換的思考來源。生活時間、額度、身份、記憶交易與工具授權仍由Kinseed控制。模型提出工具呼叫，不取得Owner憑證，也不直接執行宿主程式。把Codex作為額外手腳，是後續獨立階段，不能由本地模型接入推定已授權。

## 建議驗證順序

1. Owner選擇模型、下載時機與網路預算；先用小型量化模型驗證，不能以模型檔案大小推論完整運行記憶體或能力。
2. 取得可信官方執行程式與模型，記錄版本、模型摘要、量化及授權。採用可獨立停止的本機服務，限制loopback，不開機自啟、不啟雲端功能、不自動下載更新；若選定程式不能安全提供這些條件，另報可行替代。
3. 檢查記憶體餘裕，先量測一個合成文字工作；不在其他個體生活期間進行負載實測。`node scripts/local-model-readiness.mjs`只讀硬體，不連接模型或任何生活控制器。6 GiB餘裕為本次共機小模型試驗建議，並非官方最低需求或新權限。
4. 增加明確本地設定與接頭，區分模型服務可達、模型已存在、支援工具與實際推理成功。禁止自動pull、雲端fallback、任意外部URL、重新導向到外部服務或傳遞Owner token。設定切換只在本候選停止時進行。
5. 對話／工具循環：生活提示→本地模型→解析工具名稱與參數→既有受控MCP／broker→原始工具結果→再交模型。每次工具仍驗租約、個體、期限與權限。請教／報告為純文字，不能繼承生活工具能力。
6. 合成兩個個體驗證：身份全文承接、筆記、記憶版本及後續輪次、跨個體拒絕、無權限工具拒絕、純文字用途、不重複提交與無自動出生／恢復。上下文不足必須明示，不能默默截斷身份、記憶或工具結果。
7. 失敗驗證：服務未啟動、模型缺漏、格式錯誤、超時、斷線、工具後推理失敗、取消與重啟。HTTP取消只表示連線關閉，不能當服務已停止計算的證據；確認本次工作收尾前不釋放worker，有寫入不盲重試。
8. 真實量測輸入／輸出token、耗時、記憶體峰值與工具成功率，分開標示合成故障與真實模型結果；不足以完成生活循環時明確列出未通過項目，不以簡單聊天成功代替驗收。

## 驗收邊界

- 模型服務只接受本機開發資料；本階段不導入正式身份或歷史。
- 不改正式兩人的模型、權限、窗口、輪數、出生、身份、A或B，不重啟正式程序。
- 不因CPU推理較慢自行延長正式輪次時限或刪減記憶；需要改正式政策時另提出影響與Owner決策。
- 不保證小模型達到GPT品質。硬體可載入、能聊天、能完成工具循環、適合長期個體生活是四個不同驗證結果。
- 需要停止本地服務時只停止本候選明確持有的程序，不能清除其他服務或未知程序。
