# 工具權限的保存與生效

先選對個體 → 勾選需要的工具 → 等目前工作收尾 → 保存 → 核對「目前已生效」。每日生活開啟時也能在工作空檔保存，不必先關閉或重新開啟安排。

「目前已生效」是伺服器保存的設定；「尚未保存」是本分頁的草稿。切換個體或重新整理會保留各自草稿，不代表權限已生效。前往狀態的按鈕只切換查看，不替 Owner 啟停。

版本衝突、回應遺失不顯示成功；先更新並核對伺服器狀態再操作。成功核對後清除草稿；可放棄草稿回到已生效設定。登入、個體隔離、工作收尾、版本及六項明確布林值仍由後端檢查。郵件草稿權限不等於寄信授權。

每日授權、執行阻擋及恢復方式見 [每日生活與異常處理](LIFE_AUTHORITY_AND_RECOVERY.md)。
