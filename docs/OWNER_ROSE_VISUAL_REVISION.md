# 獨立預覽：粉色視覺修訂 02

軟體版本仍為1.12.0-ui-preview.1，本次是同一獨立候選的視覺修訂，沒有部署正式控制台，也沒有重置試用者保存的設定。

設計目標是讓操作更有層次、更值得停留研究。這是設計方向，並非宣稱已經證明付費意願或符合某項商業認證。

## 視覺關係

| 用途 | 呈現方式 |
|---|---|
| 品牌與整體環境 | 淡粉背景、白色卡片、深梅色標題；不把整頁文字都變成亮粉 |
| 閱讀順序 | 大標題、步驟小標、用途說明、欄位標籤依序區分大小、字重及留白 |
| 保存與主要確認 | 深玫瑰色填滿按鈕，每一區的主要動作與次要放棄分開 |
| 查詢與檢查 | 淡紫底、較輕的按鈕，不暗示查詢會改權限或生成 |
| 返回與放棄 | 白底與細框；不是與保存同樣強度的實心按鈕 |
| 預覽示例 | 淡金色虛線按鈕，避免把模擬入口誤認為真實服務 |
| 已勾選能力 | 粉色底、側邊標記與原生勾選框；不單靠底色表示狀態 |
| 已生效、未保存、錯誤 | 保留文字與各自的狀態區，重要警示保持獨立色彩 |
| 專業欄位與原始資料 | 收在進階區，字體與比重低於主要操作，但保持可讀 |

另補齊左側「工具與材料」目前位置標示，手機導覽維持水平閱讀，不將群組標題擠成直排。

本次沒有外部字型、圖片或其他網路資源下載。使用系統字型、CSS葉芽標誌、細緻陰影與少量過場，並尊重減少動態效果設定。核心文字色組檢查對比至少4.5:1，提供鍵盤焦點與主要按鈕觸控尺寸；這不是完整WCAG稽核或認證。

## 驗證與限制

在繁中、簡中、英文、日文及1440、1024、390、320像素寬度檢查主要五區，並用隔離合成個體回歸權限保存、Hedra及聲音流程。實際預覽資料僅唯讀核對，沒有為測試而代保存Owner草稿或重置設定。

前階段874項程式回歸與848項UI是前階段證據；本次視覺修訂的實際重驗範圍依本次交付報告，不冒稱重新跑過所有模型、寄信或生成。仍未部署正式、未上傳GitHub，等待Owner再次體驗與回饋。
