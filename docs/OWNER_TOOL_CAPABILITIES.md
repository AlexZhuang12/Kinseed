# 工具能力獨立試用版操作指南

本副本的版本是 1.4.0-tool-preview.1。資料只在本副本 .private 內，與其他安裝分開。這不是已更新的正式控制台，也沒有上傳 GitHub。

## 開始、停止與重新開啟

1. Windows 安裝 Node.js 24.19.x，並準備 Chrome；首次設定仍可選自己的 Codex 或本地大腦。新副本預設不啟用大腦，不下載或切換模型。
2. 在本副本執行 npm ci --ignore-scripts --no-audit --no-fund。套件鎖定在 package-lock.json，不執行第三方安裝腳本。
3. 執行 npm run tools:prepare，取得兩份 OCR 語言資料，合計約3.65MB壓縮。每份逐位元大小及SHA核對；缺少資料時OCR明確失敗，不能假裝完成。Pyodide核心已隨npm依賴安裝，不另下載Python整套。
4. 執行「啟動開發控制台.cmd」，再執行「開啟開發控制台.cmd」。開啟必須使用本副本的新連結，僅複製網址、不包含連結尾端的Owner憑證會無法驗證。不要分享完整連結。
5. 要停止用「停止開發控制台.cmd」。停止只針對本副本；再次啟動保留資料，但不自動恢復任何生活。遇到工作尚未收尾，先看本副本 .private/development/logs，不重複啟動或手動刪資料。

## 第一次看工具

開啟「工具與材料」，先選個體，再依六個頁籤操作：

| 頁籤 | 操作與下一步 |
| --- | --- |
| 材料收件匣 | 貼文字、公開HTTPS網址或手選一份檔案，三者擇一。核對對象及分析同意，保存獨立副本。 |
| 專案與成果 | 看版本化專案、執行結果，預覽HTML互動，下載PDF／Word／Excel。查看不派工作、不啟動生活。 |
| 工具權限 | 先停止個體與每日安排，等工作結束，勾選需要的能力再保存。保存權限不批准身份、不出生。 |
| 申請與提醒 | 看個體提出的用途與費用、批准或拒絕；已批准不等於已安裝。到期提醒不代表生活授權。 |
| 外部連線 | 看三個公開資料接頭；雲端只保存服務與資料夾設定，不實際連線。Gmail使用自己的桌面用戶端及寄送授權，每份新安裝均須自行設定。 |
| 待批准郵件 | 每封核對收件人、正文與附件，明確勾選後才送。沒有連線、有效生活及權限就不寄出。 |

合成範例若已建立，甲乙都是工程示例，未出生、停止、權限未開。範例作品與文件清楚標示工程建立，不能當作個體生成或模型驗收結果。要測自己的個體，仍依控制台身份批准與首次出生步驟，由Owner確認。

## 材料與資料流向

- UTF-8文字／Markdown／CSV／JSON、文字型PDF、Word DOCX、Excel XLSX、PNG／JPEG可匯入。每檔8MB，圖片400萬像素以內；掃描PDF沒有OCR全文保證。原檔不變，不掃描本機資料夾。
- 沒勾分析同意也能先保存，模型看不到該材料清單與原文。之後可逐份同意或撤回。文字草稿在同一瀏覽器分頁重新整理後保留；檔案要重新手選，瀏覽器不代保存本機檔案存取。
- 同意綁材料內容雜湊及目前大腦目的地。更換模型或本地服務位址後重新確認，不逐輪重問。同意雲端大腦分析代表內容會送給該大腦，不包含其他雲端儲存或公開發布。
- 已傳給模型的內容不能從遠端撤回；撤回只阻擋後續材料工具讀取，不會改寫個體既有記憶或供應商紀錄。
- 外網仍檢查私人位址、DNS、轉址、已知私人文字及流量。已知片段防護不能辨識所有改寫或語意外洩，不能當完整DLP保證。由公開網址取得的材料按公開來源處理；Owner手選與貼文仍是待保護內容。

## 程式、文件與圖片能做到哪裡

Python用Pyodide／CPython3.14.2在瀏覽器WASM執行，只能碰自己的虛擬專案檔案；JavaScript用QuickJS/WASM與自己的相對CommonJS模組。沒有Node、宿主shell、Owner檔案或任意網路。專案最多20檔、合計256KB，每次程式最多5秒；Python WASM最多256MiB，外層Windows Job程序樹768MiB。本機重型工作一次一項，忙時提示稍後再試。

互動網頁支援受控DOM子集：文字、表格、CSS圖表、欄位與按鈕click。作品JavaScript在QuickJS跑，Owner瀏覽器不執行作品腳本；不是完整Chrome網頁環境，不支援任意框架、Canvas、SVG或外部資源。作品超出能力應顯示限制，不放寬沙箱。

PDF／Word／Excel是簡單文字及表格，不含巨集、複雜公式或Office自動化。Excel數值儲存為實際數字，公式樣式文字不執行。文件輸入與產出SHA、專案版本及執行結果可追查。Word用獨立瀏覽器渲染及python-docx解析驗證，PDF實際渲染檢查，Excel以openpyxl解析；本機未裝LibreOffice，原生Office版面驗收未做。

OCR在本機Tesseract讀文字，可能有辨識錯誤，不代表看懂整張圖。MCP原圖輸入已用目前Codex大腦實測圖形與圖表；原圖上限200KB，其他大腦未驗證影像就明示不可用，不自行改接外部服務。

## 公開資料、套件及事件

維基百科文章摘要每頁3筆；Crossref書目每頁3筆；USGS近期地震目錄每頁10筆。回傳來源、時間、SHA、下一頁及自己的原始JSON快照識別碼，可用read_document分頁讀原文。每次是真實查詢，仍受原網路權限及預算，403／429／逾時或格式變更如實失敗。書目不是論文全文，地震目錄不是預警。

目前只驗證packaging26.1的固定純Python wheel。個體先申請、Owner批准固定來源／版本／SHA，再按安裝；下載計入該合成個體原額度。未知套件不會因批准就執行npm／pip，安裝失敗或不明不盲重送，沒有新增費用授權。

提醒在控制台列出並記錄到期；個體只在既有有效生活內處理，時段外留待下一次。沒有桌面推播、簡訊或外部行事曆連線。雲端設定與費用申請只有狀態管理，跨個體合作及實際付費尚未開放。

## Gmail本輪界線

本候選已完成一次真實send-only OAuth及Owner批准的合成測試信寄送；Gmail接受，Owner確認正文及PDF可讀。故障回應測試另外標示合成，不冒充真實供應商事故。來源包不含帳號、憑證或原始郵件回執，新安裝仍需自己的授權；不會沿用工程測試連線。

後續需要自己的Google桌面應用OAuth用戶端與專用測試帳號，只要求gmail.send，不讀信箱。到控制台設定用戶端、選專用帳號授權；不要把密碼貼進對話。應再核對具體測試收件人、正文、附件，批准這一封後才實際寄送。服務接受不等於收件者收到或讀過。斷線結果不明時查看寄件帳號寄件備份，再決定人工處理，不自動重寄。「中斷連線」刪本工具本地token；Google端撤銷須到帳號安全設定另做。

## 回退與保留

停止本獨立副本即可回到原來工具，正式控制器沒有更新。不要把本副本src或DB覆蓋到其他安裝。預覽資料在自己的.private；備份用npm run backup，先停止並核對工作收尾。不要用舊DB覆蓋新的身份、記憶、歷史或授權。此版本不是GitHub已發布版。
