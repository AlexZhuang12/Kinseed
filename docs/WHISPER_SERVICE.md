# 專用Whisper啟停與狀態

這是Owner管理安裝環境的功能，不是個體的MCP工具。啟動模型不會出生、恢復生活或開放hearing／media權限；停止模型也不取消每日生活。個體仍需既有生活授權、明確權限、來源版本／SHA及逐份目的地同意。

## 使用順序

1. 在「聲音理解與比較」的專用服務區按檢查狀態。此動作不讀取權重或啟動模型。
2. 提供已下載的官方b5454 Windows CPU ZIP與Whisper base多語模型絕對路徑，校驗並保存。系統只接受核定大小與SHA；不下載、不接受任意執行檔、不傳檔到雲端。程式從核定ZIP複製到這份安裝自己的私人目錄，模型檔保持原位、不改寫。
3. Owner啟動專用服務。至少3GiB可用RAM；不足時明示尚未啟動，不關其他程式。服務2執行緒、低優先順序、CPU模式。Windows Job對自己native程序樹設1GiB上限；監測可用RAM低於2GiB時停止接受新工作並收尾。這是工程預設，不是任意錄音都足夠的保證。
4. 就緒後將端點手動填入個體的本地聲音連線。端點固定保存，重啟不變；不自動改個體設定或開權限。
5. Owner停止時，已接受的原辨識先收尾，停止接新工作，不重送。一次工作最多45秒；逾時結束自己的native服務，原工作依既有工具狀態保持未知，不假裝成功或自動清除個體的暫停。

控制台與專用CMD／CLI管理相同安裝的服務。服務可與控制器分開啟停；關閉控制器不等於關掉Owner獨立啟動的模型。冷備份或正式切換前，另核對專用服務與已接受工作都已收尾。

## 身分核對與失敗收尾

控制端讀自己的私人會話資料，先用一次性nonce核對HMAC身分，再送管理憑證。無法確認時不傳送停止指令、不按舊PID殺程序、不改成其他服務。重複啟動不產生第二個模型；端點被別的程序占用會失敗，不能採用對方或換一個端點假裝成功。

代理只公開有限的健康檢查與有界WAV辨識。管理需私有憑證；跨網站Origin被拒絕，native的`/load`不作為工具公開。原始辨識與既有靜音／可疑提示政策不變。

管理程序異常退出時，父管線EOF使自有Windows Job收尾。啟動狀態不自動清除或重送。Owner可勾選「我已確認專用Whisper服務已結束」再復原殘留狀態；系統仍檢查記錄的管理／wrapper／native PID已不存在，保留原會話作稽核，只清理自己的殘留指標。PID重用或無法確認時拒絕，不能擅自關未知程序。

程式與模型信任來自核定封裝、SHA及Owner指定。Windows Job是資源與程序樹限制，**不是完整檔案／網路沙箱**；也不能保證同一Windows使用者下的惡意程序無法碰觸localhost或私人檔案。不要把模型連線當作藝術聽感或內容正確性認證。

## 資料與版本

私人設定、固定埠、會話、復原封存及native快取位於本安裝runtime下的`whisper-service/`；模型仍在Owner指定位置。這些不進公開來源包。沒有自動下載、雲端後備、付費音訊API或服務自動重啟。新安裝尚未設定時維持停止。
