# Kinseed v1.15.0-preview.1 — Windows preview

This release catches the downloadable preview up with the already-published 1.15 source line. It includes the cumulative updates since the previous published v1.6.1 preview, plus a repeatable release workflow. It remains a preview; no stable production guarantee is implied.

## Included

- Guided pink Owner console, grouped permissions and saved/draft state; four-language core journeys and setup with installation time zones.
- Hedra model inspection, scoped media capabilities/credits, original-job recovery and saved media; local film tools, generated-document readback, PDF layout and queued page viewing.
- Optional local Whisper dialogue transcription and audio-quality hints. Transcription is not emotional, musical or artistic listening evaluation.
- Durable asynchronous consultation, Owner-controlled daily consent and scoped failure recovery; general installation reports, exact-source review and archive visibility.
- Public-web privacy false-positive correction while retaining private material, credentials, local-network and budget protections.
- Exact qualification of CLI 0.164.0-alpha.11.1, retained previous qualified runtime, private bundle verification and longer bounded PDF-page read waiting.
- Automatic verified release drafts, explicit Owner publishing, pinned source/asset checks and a single documented download channel.

## Install / upgrade

Windows preview, Node 24.19.x. Download **Kinseed-Windows-source.zip**, verify **SHA256SUMS.txt**, extract to a new directory and use the included first-setup CMD. Models, dependencies and logins are not bundled. See [downloads](https://github.com/AlexZhuang12/Kinseed/blob/main/docs/DOWNLOADS.md), [installation](https://github.com/AlexZhuang12/Kinseed/blob/main/docs/PUBLIC_INSTALL_1_14.md) and [upgrade/recovery](https://github.com/AlexZhuang12/Kinseed/blob/main/docs/UPGRADE_RECOVERY.md). Stop only your own installation after its work settles, back it up, preserve private data and verify it after upgrade. Source rollback must not replace newer databases or undo an Owner stop.
