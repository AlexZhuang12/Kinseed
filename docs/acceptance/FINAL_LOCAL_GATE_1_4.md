## 診斷、修正與重驗

- Python H04同來源在外層受限工程環境停滯，在正常Windows使用者環境約3.6秒通過，最終完整回歸亦通過。未停用Chrome沙箱、Windows Job或網路封鎖，未改模型或個體條件。詳細見[Python驗收環境](../PYTHON_ACCEPTANCE_ENVIRONMENT.md)。外層限制的精確底層原因尚未定位，不將環境對照當作所有情境都無缺陷的證明。
- 首次設定UI測試誤用已有資料的預覽目錄，換時區被原保護正確拒絕。驗收腳本改用全新來源副本與既有已安裝依賴的獨立副本，不繼承私人設定或runtime。四語重驗通過，沒有移除時區保護或修改既有設定。
- 空白副本離線安裝無快取而失敗；改用同鎖檔、官方npm及停用第三方安裝腳本的正常網路安裝後通過。首次安裝需要網路，不宣稱來源ZIP包含依賴或OCR模型。
- Gmail MIME本文及附件採76欄base64，UTF-8與二進位回讀通過。原始失敗／延後證據保留，不覆寫為成功。

## 保留與限制

正式控制器沒有更新、沒有新增正式權限、沒有停止或恢復個體，也沒有操作共用聊天服務或上傳GitHub。原正式資料與服務另有私人只讀核對，不把正式資料加入來源包。

仍未驗證：第二台實體Windows、母語審閱、第三方全面人類驗收、原生Office排版、其他大腦視覺能力及長期正式負載。Google應用仍為測試模式，可能需要重新授權；不是已完成公開OAuth應用驗證。雲端僅設定，付款與跨個體合作仍排後續。

部署前需依[正式切換方案](../FORMAL_SWITCH_PLAN.md)整合正式入口、版本及依賴，先用合成資料驗證；候選來源包不是授權直接覆蓋正式程式或runtime。既有每日生活在重啟後不自動復活，新工具仍預設關閉。
