Tests cover readiness delay, parent timeout, cancellation, tool revocation, unknown results, late events, restarts, accepted-job lookup and result/history/accounting reconciliation, no cross-owner reuse, and source/adapter update and rollback without database restoration. Public source-recovery tests reconstruct exact clean historical synthetic source snapshots from SHA-bound deltas, then start each version in a fresh process; they do not depend on unpublished local folders or skip the downgrade.

The historical AS50 process-rotation single failure and one aggregate teardown stall remain root-cause-unproven. Original failures were retained privately; successful bounded reruns do not establish a root cause. Fault injection is not proof of every natural provider incident. No generic Hedra/Gmail provider migration or paid service test is claimed.

Independent human, native-language, second physical Windows and OS escape verification: **NOT_RUN**. New real-model tests, paid generation, email, performance/RAM comparison: **NOT_RUN in this publication task**. Local or cloud synthetic tests never contain real identities, private memory/history, OAuth, tokens or original works.

The source commit and final Windows workflow URL are added after the actual run passes. A push updates main; the automatic workflow only prepares a draft. Each immutable published release needs separate Owner approval.
