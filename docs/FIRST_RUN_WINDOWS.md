# 第一次安裝與選擇大腦（Windows預覽版）

## 最短操作路線

1. 取得完整來源副本並解壓縮。最外層應看到README、package.json、**package-lock.json**及「首次設定.cmd」。請使用 GitHub 的乾淨來源，不要把含私人資料的原工程根目錄當成公開來源。
2. 安裝含npm的Node.js **24.19以上、25以下**。目前只驗證Windows；Node.js下載：[官方網站](https://nodejs.org/)。
3. 雙擊「首次設定.cmd」，保留命令視窗。瀏覽器會開啟自己的本機設定頁；若沒有自動開啟，使用命令視窗顯示的本次連結。也可在來源目錄執行 `npm run setup`；設定程式本身不需要先安裝專案依賴。
4. 依序完成下方五步。設定只作用於這份副本，不複製其他環境的個體資料。

## 五個步驟

| 步驟 | 要做什麼 | 完成後會發生什麼 |
|---|---|---|
| 1．檢查與安裝 | 查看Node與套件狀態，按「安裝程式需要的套件」 | 依鎖定版本安裝到這份副本的node_modules。不使用管理員、不執行套件安裝腳本、不安裝模型。 |
| 2．選擇大腦 | 選「先不接」、自己的Codex，或本機Ollama模型 | 只檢查接頭。選本地時需按檢查才連線；清單只讀已有模型，不下載、載入或推理。 |
| 3．準備工具 | 決定是否準備Codex受控作品工具接頭 | MCP自動接好，不須輸入JSON或通訊埠；仍未開放任何個體的工具權限。 |
| 4．確認保存 | 看白話摘要，確認大腦、工具及資料位置後保存 | 既有設定先備份。保存不建立身份、不批准、不出生、不解除停止、不恢復生活。 |
| 5．開啟控制台 | 按啟動，再按進入控制台 | 新副本使用空資料；再次啟動保留本副本的資料，依已保存的每日授權核對排程；Owner明確停止不自行恢復。 |

上一步及重新整理會保留本瀏覽器分頁的選擇。關閉後再次執行時可讀取已保存設定；未保存選擇不是正式設定。設定已被另一個視窗修改時會拒絕覆蓋，請按「重新讀取已保存設定」後重新核對。網路斷線後重按相同保存，若已保存同一份內容，不會重複覆寫。

## 選擇Codex

目前支援已驗證的CLI **0.164.0-alpha.11.1（亦保留已驗證的0.163.0-alpha.10.2）**及GPT-6.1-Sol／low組合。可以使用已有支援版本，或按導引的「安裝指定版本」裝到這份副本的.private/codex-cli，不更新全域或Desktop的程式。安裝需要網路與磁碟空間，只從公開npm登錄取得固定版本；不自動接受其他版本。

按「檢查版本與登入」只執行版本／登入狀態檢查，不呼叫模型。如果未登入，按開啟登入視窗，**自行在Codex官方登入流程完成驗證**；導引不收密碼、權杖或複製帳號檔案。登入狀態仍由Codex依這個Windows使用者的正常登入位置管理，不是另外建立一套Kinseed帳號；本次工程驗收沒有替Owner登入或切換帳號。

官方參考：[CLI安裝](https://developers.openai.com/codex/cli)、[登入](https://developers.openai.com/codex/auth)。公開登錄已確認上述版本存在，但即時下載與帳號模型容量不能保證永遠可用。預檢通過不表示任何模型任務都成功或不會容量不足。

## 選擇本地模型

先自行準備Ollama及模型，保持服務開啟，再輸入本機服務位址。只接受127.0.0.1 HTTP，不接受外部服務、帳密、代理或正式控制器埠。按檢查列出模型，選擇一個已有模型，再繼續。服務清單沒有模型時，先自行安裝模型再重查；導引不會替你下載。

進階設定可選文字容量、回答預留及工具互動格式。預設逐次選一個工具；沿既有通用契約，不為某一模型補答案或記憶。模型需提供文字與工具能力及足夠上下文；檢查失敗會顯示原因。檢查只讀metadata，不代表完整生活能力或速度已通過實測。原Qwen小模型的生活資格仍未通過；不能因為選單可選就宣稱合格。

## Codex／MCP工具與個體權限

「大腦」負責思考與選擇；「Codex工具接頭」負責受委派的作品工作，可以分開選。即使選本地大腦，也可準備Codex工具，但工作內容會送給Codex並使用帳號額度。每輪最多一次委派，另占個體與平台一次模型嘗試。

Kinseed MCP使用程式自己的設定與短效能力，不改使用者全域MCP設定。此版只支援Kinseed已有的受控工具，尚無任意第三方MCP安裝入口。詳細範圍見[工具接口指南](CODEX_TOOL_INTERFACE.md)。

完成初次設定後，仍須到「管理個體→工具權限」明確選擇要給哪個個體開放；編輯及隔離執行亦需原權限。準備接頭不會代替Owner批准身份或首次出生。

## 重新開啟、停止與改設定

- 設定頁重新整理後，可用「開啟已在執行的控制台」找回同一份副本的連線。
- 使用設定頁的停止按鈕，或這份副本的「停止開發控制台.cmd」。停止只作用於已驗證屬於本副本的控制台；不會去停止其他環境。
- 要換大腦或安裝套件，先停止這份控制台，再重新執行首次設定。執行中不切換設定。保存不恢復生活。
- 私人資料在.private，自己的設定在config/development.local.json；舊設定備份在.private/setup-backups。不要分享.private、私人設定、日誌、模型輸出或連線網址。

若連線檔存在但服務沒有確認關閉，導引會拒絕安裝／覆寫，請先用本副本停止入口確認。不要為了通過檢查任意刪除DB、未知工作或舊授權；真正異常退出後需核對連線及工作收尾，這個安裝導引不提供無證據清空功能。

## 原始碼包、限制與回退

這是獨立Windows預覽環境，已採Apache-2.0、尚未發布GitHub；不宣稱在第二台實體電腦驗收，也不直接套用到既有正式資料。不要將候選整目錄覆蓋其他服務。

建立乾淨來源包時執行 `node scripts/export-source.mjs`；輸出在本副本的.private/exports。允許清單包含package-lock.json及必要標記，不含私人設定或資料。**npm pack會刻意省略package-lock.json，不能直接拿其清單當作此工具的完整來源安裝包。**

要回退設定，先停妥本副本，保存目前config/development.local.json，再將本次備份的設定放回該檔。既有資料、作品、出生及歷史不回退；不以舊DB覆蓋新生活史、不恢復舊生活授權。若只想暫時停用，在導引選「先不接大腦」及關閉Codex工具後保存即可；私人資料保留。

大型CLI安裝會顯示實際下載量並保留已收到的片段。只有完整程式包通過官方SHA-512校驗後，才會離線安裝並核對執行檔版本；片段或檔案長度不代表完成。每次下載有10分鐘上限，中斷後可再按安裝繼續，不需要整包重抓。這是程式下載，不是模型下載。

要換瀏覽器，請用設定頁的「複製可在其他瀏覽器開啟的設定連結」或「複製控制台連結」，不要只複製位址列。完整連結含本次操作驗證，請勿分享給他人。瀏覽器不允許複製時，可從命令視窗取得完整設定連結。


控制台內可隨時開啟「操作導引」。完整接續流程見 [Owner快速指南](OWNER_QUICK_GUIDE.md)。
