# Python驗收環境與停滯診斷

Python使用Pyodide/WASM，執行於啟用沙箱的Chromium，外層Windows Job限制程序樹記憶體並於關閉時收尾。這與執行工程測試的外層受限環境是兩個不同邊界。

同一H04測試、同一來源及依賴的對照：正常Windows使用者環境約3.6秒通過，包含自己的多檔案、拒絕宿主檔案及拒絕網路；外層受限工程環境超過15秒，測試宣告逾時後仍未正常退出。後者保留失敗證據並只收尾該次測試程序樹。這證明停滯與執行環境有關，但未定位至單一Windows內核限制；不能僅憑對照宣稱產品不存在其他問題。

驗收請在允許Chromium沙箱與Windows Job啟動的正常Windows使用者環境執行npm test及UI測試。不要加--no-sandbox、移除Job限制、改為宿主Python或任意提高資源上限。受限執行器無法啟動時應記錄環境阻塞，而非當作測試通過。外層測試執行器若逾時但仍留存程序，先核對本次專用PID與命令列，只收尾它的程序樹，不關閉使用者Chrome或其他服務。

本次修正是選用正確的驗收執行環境、補齊文件與可重現對照；沒有為模型加特例，沒有更換Python隔離架構或放寬個體權限。最終整版回歸另保存實際結果，不能以此單一案例代替全套驗收。
