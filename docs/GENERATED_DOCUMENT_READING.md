# 讀回自製文件與預覽原始頁面

## Owner

控制台「工具與材料」→選個體→「專案與成果」。PDF旁的「預覽PDF頁面」會顯示已保存原檔的實際頁面，可上一頁、下一頁或關閉。這是靜態影像，頁面中的連結、腳本與附件不會執行；不會重新製作或改寫作品。切換個體會清除先前頁面。Word／Excel仍可下載檢視。Owner可以查看自己的平台保存成果，不因個體目前的權限撤回而丟失檔案。

## 個體工具

- document_create回傳id及document_id，同一文件並非兩份；read_tool與view_tool提示下一步。舊文件原ID也直接有效，不需重製或移資料。
- read_document讀取自己製作PDF／Word／Excel的實際保存內容，沿用文件權限。PDF回傳真實頁數，其餘不虛構頁數。原網頁快照／下載文件讀取維持原規則。每次最多6000字元，以next_offset續讀。
- document_view({document_id,page})一次取得已保存PDF的一頁PNG，頁碼從1開始。個體須有原文件及圖片閱讀權限，目前僅已驗證MCP視覺輸入的Codex接頭可取得模型影像；其他接頭明確說明未支援，不冒稱看懂。
- 回傳source_sha256、image_sha256、頁碼、頁數與尺寸，區分原檔及影像。頁面已提供不代表模型完成理解，文字抽取也不是已確認版面。

## 邊界與限制

只從自己的資料庫讀取，不接受本機路徑，不讓文件ID跨個體。內容須通過原始大小及SHA核對；校驗失敗不使用快取繞過。既有文件上限8MB、PDF最多200頁、單頁最多400萬像素，渲染寬度上限1100px、PNG上限1.5MB，單一重型轉換工作、Windows Job及Chrome沙箱仍有效。

PDF.js使用現有鎖定unpdf套件。只提供該固定本地程式碼給隔離渲染器，其餘外網、檔案、WebSocket均阻擋；不下載新引擎或放寬控制台CSP。頁面使用Canvas顯示，無需允許額外圖片來源。

文字可能保留PDF自身的換行及字型對應差異；回傳提示不把形近字元自動改成新原文。Word／Excel讀取也有原生活期限、取消與程序收尾。接近收尾不開新的頁面渲染；不延時、不增加輪數、也不替個體寫記憶。

本次只補功能，不自動開啟任何個體的新權限、不重做既有作品、不向個體傳訊或改其原生條件。
