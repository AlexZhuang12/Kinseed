# Film candidate AI acceptance

Version **1.9.0-film-preview.1**. Independent synthetic Windows installation. No existing individual, shared service, formal controller or private work was used for testing. This is not a public release.

## Executed evidence

- Full program regression: **807 passed, 0 failed**. Four-language browser regression: **31 scripts / 692 checks passed**. Clean-install, backup and restart: **13 checks passed**. Independent entry: **8 checks passed**. Real-model three-round integration: **15 checks passed**. The UI suite covers isolated playback, actual video advancement, download hashes, separate permission drafts, cross-individual separation and no automatic life.
- Synthetic clips and pure tone are created by the isolated FFmpeg/WASM engine, then trimmed, concatenated, mixed, captioned, decoded and sampled. Changing captions reuses unchanged clip steps and retains both project versions. Frame review, waveform and audio-segment behavior are tested separately.
- A real Codex brain completed **three rounds** through the real controlled MCP interface: authored a timeline/captions, submitted a local render, continued from its own memory, requested a timed frame, actually received the image, and authored review and memory. The harness did not supply its captions, judgments or memories. Separate fixed scripted tests are explicitly identified as harness evidence, not model creativity.
- The model's visual review sampled 1200 ms. It did not claim to watch the whole moving film or hear the audio. Engineering visual QA additionally inspects frames across the cut. Browser and decode checks are separate from semantic understanding.
- Current Hedra speech/effects schemas and a queried shared-library voice search were verified through the actual candidate read-only connection; reported available credits were unchanged before and after that check; private account balances are excluded from this public summary. No voice cloning, private voice library listing, billing-mode change or paid generation occurred.
- Failures cover source hashes, foreign IDs, schema/parameter injection, storage/size limits, active cancellation, permission withdrawal, restart, finite explicit retry, unknown paid submission and preserved daily authority. Cold backups reject unknown formats, corrupted ledgers and live senders; no old database restore command is introduced.
- Source/dependency integrity and clean-install/backup/start-stop checks are recorded separately. No third-party human, native-language or second physical Windows acceptance is claimed.

## Diagnoses retained, not hidden

Early loader asset addressing failed and was corrected without opening network access. Initial tests assumed a daily-state row existed in a fixture that had not enabled daily life; the fixture was corrected through the real Owner daily-authorization path. An existing permission test was updated to explicitly leave the new media flag off, preserving its original assertions.

Stricter full-decode testing exposed a real FFmpeg/WASM ordering defect: running ffprobe before FFmpeg in the same module could yield missing decode/volume evidence. The order was fixed, probe is constrained to the final step, and QC now requires a completion footer plus volume measurements when audio exists. Metadata success alone is not a technical acceptance pass. Earlier failed logs remain retained.

A clean installation also exposed the old maintenance inspector rejecting the Hedra ledger. A dedicated read-only schema/history/owner/outbox checker was added; unknown schemas and active owners still fail closed. Installation and backup are rerun after this correction.

## Limits and next gates

Real paid speech/effect/reference/video generation has **not** been validated in this iteration. The synthetic integration is not a claim about external model quality or refunds. Current audio semantic understanding remains unsupported; actual audio can be played by Owner, and technical statistics/waveforms do not establish listening. Larger/longer projects, professional quality and lip sync are outside this qualified scope.

Formal deployment, new formal permissions, a concrete paid test and GitHub publication require separate Owner decisions. GPL FFmpeg/core retains its terms; corresponding-source and nested-codec distribution obligations must be reviewed before public redistribution. See FILM_WORKFLOW.md.
