# 第3階段真實本地模型驗證：尚未通過生活驗收

2026-10-21已在獨立資料區實測Ollama與Qwen3 1.7B Q4_K_M。沒有更換正式模型或啟動正式個體；本開發版預設大腦保持停用。

逾時修正已逐檔合併，保留接頭的大腦來源欄位；沒有用正式src覆蓋整份開發來源。新增截止競態與原安全邊界案例。

實際完成12次短文字工作，含載入約2.4–3.4秒，生成約17–21 token/秒。只代表短輸出；不代表完整生活速度。測試使用CPU，短工作2執行緒／2048上下文，工具循環使用引擎預設8執行緒及12288／14336上下文。

獨立測試服務及子程序觀測工作集最高約3.0 GiB，private bytes約3.1 GiB；量測期間系統最低可用約1.67 GiB。這是這台電腦的取樣結果，不能當所有硬體或完整大身份的需求。測試服務與共用聊天各自使用不同埠、profile及模型副本；沒有呼叫共用聊天的推理接口。

真實MCP get_context成功，但沒有成功保存筆記或commit_cycle；記憶跨輪承接未能進入實測。模型有重複工具參數、檔名不符Schema等問題，錯誤回饋未能促成完整提交。完整工具／生活提示在8192保守預算被拒絕；完整問卷格式與工具回傳的多層JSON表示也占用較大預算。這不等於模型原生上下文已滿，模型metadata宣告40960；原檢查採UTF8位元組保守上界，尚未完成精確tokenizer及截斷驗證。

本次在開發版補上標準user工作訊息、可選的縮小工具清單、單文字MCP外殼的無損展開及相同失敗參數停止（忽略物件鍵順序）。不猜改參數、不改身份內容、不刪記憶、不放寬工具驗證。工具清單預設仍完整，可選縮小集合必須保留get_context與commit_cycle，且不能加入MCP未提供的工具。多部分或有額外metadata的工具結果保留原表示，不丟棄內容。工具作用與原始B仍由MCP及控制器決定。

真實取消時HTTP結束不冒稱模型計算已結束，worker／租約確實保留。測試程式最後只停止自己明確持有的獨立服務程序樹，確認程序與埠關閉、MCP退出後，以真實程序退出收據結算自己的合成個體。這不證明共用Ollama已有可依賴的請求級取消；產品取消仍保留未知收尾防護。

110項開發環境／大腦／協定／合成個體測試通過，但不取代上述真實模型未通過項目。正式資料前後核對保持；無正式資料或Owner／cycle能力憑證送給模型。

下一步應先驗證精確token預算與完整工具資料呈現，再改善通用工具呼叫可靠度，並重新測完整生命週期。不要因簡單文字成功就切換正式個體，也不要直接進入Codex委派或更換模型。是否比較其他模型、提高硬體資源或正式切換，另由Owner決定。

回退只還原本次開發來源變更、移除新增測試及說明；開發設定仍停用，沒有正式部署可回退。不還原正式資料庫，不刪歷史或重啟舊授權。真實私有證據留在工程工作區，不納入可發布套件。
